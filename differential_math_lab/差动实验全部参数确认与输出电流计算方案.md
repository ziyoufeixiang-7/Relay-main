# 差动实验全部参数确认与输出电流计算方案

> 分析范围：`RelayProtection/api/ApiDiffTest.py`、`RelayProtection/calc/diff_bridge.py`、`RelayProtection/calc/diff.py` 及当前差动 API 文档。
>
> 文档目的：先把前端参数的业务含义逐项确认，再确定一套能覆盖全部参数、全部相别和两种接线方式的输出电流计算方法。
>
> 当前状态：参数确认稿和算法设计稿；没有修改生产代码。
>
> 公式格式：只使用 VSCode Markdown 预览可识别的 `$...$` 和 `$$...$$`。

## 0. 先说结论

差动实验不能仅凭 `Ir`、`Id`、`K` 三个数直接唯一得到 Ia、Ib、Ic、Ix、Iy、Iz。完整输出还取决于：

- `Id/Ir` 方程及两侧相对极性；
- `Kp1/Kp2` 的定义和作用方向；
- A、B、C、AB、BC、CA、ABC 的业务语义；
- 保护内部的接线组别、相位补偿和零序滤除矩阵；
- 两组三相电流与保护端子的排列、极性和相序；
- 稳态差动、零序差动、工频变化量差动对故障前/故障后状态的不同定义；
- `loadCurrent` 是否以及怎样叠加；
- 数值是有效值还是正弦幅度值；
- 谐波百分比、谐波角度和谐波相序的定义。

当前程序没有真正使用其中若干参数，而且 A/B/C 与 AB/BC/CA/ABC 走的是两套不同的算法。因此本文分成三层：

1. 第 1 章是需要你核对的参数语义；
2. 第 2～6 章准确说明当前程序实际上怎样计算；
3. 第 7～13 章给出参数确认后应采用的统一专业算法。

在第 1 章确认之前，第 7 章以“建议口径”描述，不把尚未确定的假设冒充为最终协议。

## 1. 第一部分：请先核对这些参数含义

后续可以直接按编号回复，例如：

```text
C02：points 是有效值，statics 是幅度值；
C07：AB 表示 AB 相间故障；
C10：loadCurrent 是保护补偿域侧1有效值；
其余确认。
```

### 1.1 会直接决定六路电流的核心确认项

| 编号 | 参数或规则 | 本文暂定理解 | 为什么必须确认 |
|---|---|---|---|
| C01 | `I1`、`I2` | I1 是参与差动计算的侧 1，通常为高压侧；I2 是侧 2，通常为低压侧。它们是逻辑侧，不等于固定物理通道。 | `i1Terminal/i2Terminal` 可以交换两组输出；三绕组时“侧 1/侧 2”还必须对应到明确绕组。 |
| C02 | `points[].x/y` 的单位 | 建议：差动坐标 `Ir/Id` 使用有效值 RMS；所有内部相量也用 RMS，仅在写入 FPGA 前乘一次 $\sqrt 2$。 | 当前代码把点值乘 $\sqrt2$，但当前 API 文档又写“不换算”；如果前端已经给幅度值，当前输出会大 $\sqrt2$。 |
| C03 | `params.statics` 的单位 | 按项目通用约定，交流层中的物理值已经是幅度值，不再乘 $\sqrt2$。 | 它与 `points` 可以采用不同口径，必须分层说明，不能对整个 JSON 统一乘 $\sqrt2$。 |
| C04 | `isPerUnit` 与 `Ie` | 建议：线性差动坐标为标幺时，先在标幺域求解，最后把两侧补偿域相量乘 `Ie`。`Ie` 是保护补偿域的基准有效值。 | 当前代码直接把 `Ir`、`Id` 都乘一次 `Ie`；平方型方程不能这样处理。 |
| C05 | `Kp1/Kp2` | 暂定保护内部执行 $J_s=Kp_s C_s I_s$，所以测试仪反算时除以 `Kp`。`Kp` 已包含 CT/额定电流不平衡，不再重复乘变比。 | 某些保护把同类参数定义成 tap 除数；如果方向相反，全部输出幅值都会错。 |
| C06 | `idEquation/irEquation` | 以第 3.3 节列出的字面公式为准，并只允许经过确认的合法组合。 | 当前代码把多种并不等价的制动方程合并到了同一个求解器。 |
| C07 | `testPhase=AB/BC/CA/ABC` | 建议按物理故障型理解：AB 为 A、B 等幅反向；ABC 为 ABC 正相序平衡三相。 | 如果前端含义是“同时测试 A、B 两个独立差动元件”，相角模板就不一定是 `[1,-1,0]`。 |
| C08 | `testPhase=A/B/C` | 对不滤零序的全秩保护，可用单相单位向量；保护内部滤除零序时，采用与昂立实测一致的可实现差动环，而不是强求补偿后只有一个相非零。 | 去零序矩阵的秩为 2，纯 `[1,0,0]` 不在其值域内，数学上没有精确逆解。 |
| C09 | `highClock/lowClock` | 暂定两者是当前参与试验的两个绕组相对于同一参考的绝对钟点，先算相对角 $\Delta=(high-low)\times30^\circ$。 | 当前单相代码完全忽略 `highClock`；多相代码则错误地按每侧自己的绝对 clock 选矩阵。 |
| C10 | `phaseCorrection` | 它表示被测保护内部在哪一类绕组侧做相位校正，而不是测试仪随意旋转哪一侧。`none` 表示保护内部不校相；`y-side`、`delta-side` 必须映射为保护实际矩阵。 | Y/Y 或 D/D 时可能两侧都匹配，仅凭一个字符串仍不足以知道每侧采用哪一个矩阵角。 |
| C11 | `zeroSequenceCorrection` | 它表示相差动比较前对指定 Y 侧扣除零序，与 `diffMode=1` 的“零序差动元件”不是同一概念。 | 当前单相经验分支在 Y/D 场景中可能连 D 侧也追加对消通道。 |
| C12 | 系统相序和 CT 极性 | 暂定系统为 ABC，相 1/2/3 分别为 A/B/C，保护端子极性由 I1/I2 接线配置固定。 | 当前协议没有 `ABC/ACB`、CT 星点方向或相序置换字段；现场不同就不能只靠钟点数计算。 |

### 1.2 两状态和差动模式确认项

| 编号 | 参数或规则 | 本文暂定理解 | 为什么必须确认 |
|---|---|---|---|
| C13 | `diffMode=0` | 稳态差动：故障前可输出穿越负荷；故障态由目标 `Id/Ir` 电流替换故障前负荷，不叠加 `loadCurrent`。 | 当前代码无论 `loadCurrent` 为多少，故障前六路都为 0。 |
| C14 | `diffMode=1` | “零序差动”需要先确认是两侧 $3I_0$ 比较、普通零序差动，还是 REF/限制接地故障。 | 若涉及中性点 CT，当前 6 个相电流通道、现有端子字段和方程字段不足以唯一实现。 |
| C15 | `diffMode=2` | 工频变化量差动：`Id/Ir` 对应故障增量；Node 1 输出穿越负荷，Node 2 输出“穿越负荷 + 目标增量”。 | 需要保护建立记忆量，因此通常必须 `simulatePreFault=true`，且预故障时间必须覆盖保护记忆窗。 |
| C16 | `loadCurrent` | 建议定义为保护补偿域侧 1 的三相正序穿越负荷有效值，A 相参考角为 0°；侧 2 极性按 `idEquation` 的穿越对消方向设置。 | 当前只有幅值，没有负荷角、相序和“物理侧/补偿侧”说明。 |
| C17 | `simulatePreFault=false` | 稳态项目可以直接进入故障态；工频变化量项目原则上不允许，除非明确依赖保护已存在的外部记忆状态。 | 否则变化量元件的基准不可控。 |

### 1.3 2I 与谐波确认项

| 编号 | 参数或规则 | 本文暂定理解 | 为什么必须确认 |
|---|---|---|---|
| C18 | 2I 的 `iab/iabc/ixy/...` | 暂定表示多个测试仪电流源物理并联后接到同一个保护端子，因此各源同相、总电流均分为 N 份。 | 如果它表示接到保护的不同相端子，就不能同相均分，必须按多相相量模型处理。 |
| C19 | 2I 的 $\sqrt3$ 和相角补偿 | 建议把外部接线、Kp、$\sqrt3$、clock 和极性统一成每侧一个复数增益 `g1/g2`，而不是仅按 Y/D 字母硬乘 $\sqrt3$。 | 当前 2I 忽略两个 clock 和零序设置，而且侧 2 又额外加了 180°，与 6I 极性不一致。 |
| C20 | 谐波 `x` 的基准 | `relative` 暂定为“施加侧保护补偿域 N 次谐波有效值 / 同侧基波有效值 ×100%”；`absolute` 暂定单位为 A RMS。 | 当前代码直接按物理通道的基波计算百分比，未经过 Kp/接线补偿。 |
| C21 | 谐波角和三相相序 | 需要确认 N 次谐波的初相角；若模拟真实三相 N 次谐波，其空间相序应随 N 改变，而不是所有层沿用基波角。 | 当前协议没有 `harmonicAngle`，代码给谐波层和基波层写同一个角。 |
| C22 | `applySide` | 暂定 `i1/i2` 表示只在该保护侧注入励磁涌流型基波和谐波，另一侧为 0。 | 需确认是逐相闭锁、交叉闭锁还是三相公共闭锁。 |
| C23 | `frequency` | 暂定为本次实验基波频率，N 层谐波实际频率应为 $Nf_1$。 | 当前差动 API 不读取该值，FPGA 仍沿用 0 节点的 50 Hz。 |

### 1.4 本文建议优先确认的五项

如果暂时不想一次确认全部内容，至少先确认：

1. C02/C03：`points` 与 `statics` 分别是 RMS 还是幅度值；
2. C05：`Kp` 是保护内部乘数还是除数；
3. C06：前端允许的 `Id/Ir` 方程组合及每个公式；
4. C07/C08：A、AB、ABC 的准确业务含义；
5. C09～C12：保护实际补偿矩阵、相序和 CT 极性。

这五项没有锁定时，即使算法内部自洽，也可能只是“算出了一组六路电流”，并不能保证昂立和被测保护看到相同的 `Id/Ir`。

### 2.1 外层、系统和静态量

| 路径 | 类型/默认值 | 当前代码用途 | 是否影响输出电流 |
|---|---|---|---|
| `module` | 必须为 `differential_test` | 选择 `ApiDiffTest` | 决定是否进入本实验 |
| `cmd` | `start/stop` | 启停实验 | 不改变幅相 |
| `params.debounce` | 数值，默认 20 ms | `EngineCtrl` 实际读取并设置 DI 防抖 | 只影响动作判定 |
| `params.sys.logicMask` | 整数，默认 7 | Node 2 的 DI 匹配掩码 | 只影响何时结束故障态 |
| `params.sys.debounce` | 任意 | 当前没有代码读取 | 无效；现有 API 文档把它写在这里是错误的 |
| `params.statics` | 通道→层→`[幅值,频率/角度]` | 复制电压等基础输出 | 间接影响被测保护，但不参与差动电流反算 |
| `params.limits` | 可选 | 当前差动 API 不读取 | 无 |
| `params.steps/count/testPoints` | 可选 | 当前差动 API 不读取 | 无 |

`statics` 的 API 通道如下：

| API 通道 | 名称 | API 通道 | 名称 |
|---:|---|---:|---|
| 0 | Ua | 6 | Ia |
| 1 | Ub | 7 | Ib |
| 2 | Uc | 8 | Ic |
| 3 | Ux | 9 | Ix |
| 4 | Uy | 10 | Iy |
| 5 | Uz | 11 | Iz |

层含义：

- layer 0：`[直流分量, 基波频率Hz]`；
- layer 1：`[基波正弦幅度, 相角°]`；
- layer N：`[N次谐波幅度, 相角°]`。

当前差动代码会先复制 `statics`，随后把 6～11 的整个层字典替换掉。因此：

- 电压通道 0～5 的所有层原样保留；
- 故障前 Ia～Iz 始终被改成 layer 1 的零电流；
- 比率故障态 Ia～Iz 只保留代码计算出的 layer 1；
- 谐波故障态只保留 layer 1 和指定的谐波层；
- 前端在 `statics` 中预设的电流、频率层或其他电流谐波层都会被删除。

### 2.2 方程参数

| 路径 | 当前默认值 | 建议业务含义 | 当前是否使用 |
|---|---:|---|---|
| `equationSettings.idEquation` | `id_sum` | 动作量公式 | 比率项目使用；谐波项目忽略 |
| `equationSettings.irEquation` | `ir_diff_k` | 制动量公式 | 比率项目使用，但组合不校验 |
| `equationSettings.kFactor` | 2.0 | 制动公式中的 K | 比率项目使用 |
| `equationSettings.kp1` | 1.0 | 侧 1 幅值平衡/抽头系数 | 比率项目使用 |
| `equationSettings.kp2` | 1.0 | 侧 2 幅值平衡/抽头系数 | 比率项目使用 |
| `equationSettings.Ie` | 1.0 | 标幺基准电流 | `isPerUnit=true` 时使用 |
| `equationSettings.isPerUnit` | false | 点值是否为标幺 | 比率和谐波均读取 |

注意当前类型处理：

- `Ie` 被强制转成 `float`；
- `kFactor/kp1/kp2` 没有强制转数值，字符串可能导致运行错误；
- `isPerUnit` 使用 Python 的 `bool(value)`，所以字符串 `"false"` 反而会被当成 true；必须发送 JSON 布尔值；
- `kp=0` 当前会被当成“不做除法”，而不是非法配置；
- 未知方程不会可靠报错，部分路径会回退为 `I1=Id、I2=Ir`。

### 2.3 保护补偿参数

| 路径 | 当前默认值 | 暂定含义 | 当前代码情况 |
|---|---|---|---|
| `vectorGroupLetter1` | `y` | 侧 1 绕组 Y/D | 比率使用 |
| `vectorGroupLetter2` | `y` | 侧 2 绕组 Y/D | 比率使用 |
| `vectorGroupHighSideClock` | `0` | 侧 1 钟点数 | 6I 多相使用；6I 单相忽略；2I 忽略 |
| `vectorGroupLowSideClock` | `0` | 侧 2 钟点数 | 6I 使用；2I 忽略 |
| `vectorGroupClock` | `0` | 旧协议的单一 low clock | 只有未发送 HighSideClock 键时才兼容读取 |
| `phaseCorrection` | `none` | `none/y-side/delta-side` | 6I 与 2I 都用，但算法不同 |
| `zeroSequenceCorrection` | false | Y 侧零序滤除 | 仅 6I 比率使用 |

新旧 clock 兼容逻辑有一个容易遗漏的条件：

- 只要 JSON 中存在 `vectorGroupHighSideClock`，就读取 High 和 Low 两字段；
- 如果缺少 High 字段，即使单独发送了 `vectorGroupLowSideClock`，代码也不会读它，而是回退到旧字段 `vectorGroupClock`。

当前没有 0～11 范围校验。非数字会抛异常，负数或大于 11 的整数会继续进入模运算。

### 2.4 接线参数

| 路径/枚举 | 含义 | 当前行为 |
|---|---|---|
| `connectionSettings.type=ext-differential` | 扩展差动 6I | 计算两组三相相量 |
| `connectionSettings.type=phase-differential` | 分相差动 2I | 计算两个标量总电流 |
| 其他 `type` | 非法 | 当前静默按 2I 处理 |
| `i1Terminal=high-y` | 侧 1 写 Ia/Ib/Ic | 6I |
| `i1Terminal=low-y` | 侧 1 写 Ix/Iy/Iz | 6I |
| `i2Terminal` | 同上 | 6I 侧 2 |
| `ia/ib/ic/ix/iy/iz` | 一个测试仪通道 | 2I |
| `iab/ibc/ica/ixy/iyz/izx` | 两个源并联 | 当前同相且各输出总电流的 1/2 |
| `iabc/ixyz` | 三个源并联 | 当前同相且各输出总电流的 1/3 |

若 I1 和 I2 选择了重叠物理通道，当前代码不会拒绝，后写入的 I2 会覆盖 I1。专业实现必须在发波前检查两侧通道集合不相交。

特别注意：`type=phase-differential` 时如果省略端子，当前默认值仍是 6I 的 `high-y/low-y`。它们在 2I 表中都是非法值，都会回退为 Ia，最终 I2 覆盖 I1，只剩一路输出。

### 2.5 项目、相别和试验点

| 路径 | 枚举/默认 | 当前用途 |
|---|---|---|
| `variant` | 如 `six_channel` | 当前完全忽略 |
| `activeProject` | `ratio-fixed`（默认）、`ratio-search`、`harmonic-fixed`、`harmonic-search` | 选择运行流程 |
| `testPhase` | A（默认）、B、C、AB、BC、CA、ABC | 6I 使用；2I 忽略 |
| `ratio.points` | 数组 | 比率项目的点 |
| `harmonic.points` | 数组 | 谐波项目的点 |
| `precision` | 0.01 | 搜索收敛精度 |
| `method` | `binary/linear` | 当前忽略，始终二分 |
| `frequency` | 通常 50 Hz | 当前忽略 |

后端通过 `activeProject.split("-")[0]` 得到 `ratio` 或 `harmonic`，然后只从对应子对象读取 `points/precision`。如果子对象存在但为空，不会再回退到 `projectSettings` 顶层。

点结构：

| 项目 | 点结构 | x/y 含义 |
|---|---|---|
| `ratio-fixed` | `{id,x,y}` | `x=Ir`，`y=Id` |
| `ratio-search` | `{id,x,y:[y0,y1]}` | 固定 `Ir=x`，搜索 `Id` |
| `harmonic-fixed` | `{id,x,y}` | `x=谐波值`，`y=基波Id` |
| `harmonic-search` | `{id,y,x:[x0,x1]}` | 固定 `Id=y`，搜索谐波值 |

### 2.6 两状态参数

| 路径 | 默认值 | 设计含义 | 当前行为 |
|---|---:|---|---|
| `diffMode` | 文档枚举 0 | 0 稳态、1 零序、2 工频变化量 | 完全未读取，三种模式输出相同 |
| `preFaultDuration` | 1000 ms | 故障前持续时间 | 使用 |

当前物理状态实际是：

```text
simulatePreFault=true:
    Node 1：前端电压 + 六路零电流
```

## 3. 所有方程枚举及必须采用的原始定义

### 3.1 符号

- $\mathbf J_1,\mathbf J_2$：保护完成 Kp、相位和零序补偿后，真正进入差动方程的复相量；
- $A=|\mathbf J_1|$、$B=|\mathbf J_2|$：两侧补偿域幅值；
- $\delta=\angle\mathbf J_2-\angle\mathbf J_1$：两侧补偿域夹角；
- $D=Id$、$R=Ir$：前端目标点；
- $K$：`kFactor`。

### 3.2 动作电流

| `idEquation` | 原始公式 |
|---|---|
| `id_i1` | $D=|\mathbf J_1|$ |
| `id_sum` | $D=|\mathbf J_1+\mathbf J_2|$ |
| `id_diff` | $D=|\mathbf J_1-\mathbf J_2|$ |
| `id_sum_sq` | $D=|\mathbf J_1+\mathbf J_2|^2$ |
| `id_diff_sq` | $D=|\mathbf J_1-\mathbf J_2|^2$ |

### 3.3 制动电流

| `irEquation` | 当前 API 文档给出的原始公式 | 必须确认的点 |
|---|---|---|
| `ir_i2` | $R=|\mathbf J_2|$ | 仅自然配合 `id_i1` |
| `ir_diff_k` | $R=|\mathbf J_1-\mathbf J_2|/K$ | K 在分母 |
| `ir_sum_k` | $R=|\mathbf J_1+\mathbf J_2|/K$ | K 在分母 |
| `ir_max_k` | $R=K\max(A,B)$ | 当前代码按 $\max(A,B)=R/K$，与此式一致 |
| `ir_i2_k` | $R=K B$ | 当前代码按 $B=R/K$ |
| `ir_id_abs_diff` | $R=|D-A-B|$ | 公式本身没有 K；当前代码只有 K=2 时才可能等价 |
| `ir_sum_div_k` | $R=(A+B)/K$ | 它是幅值和，不是相量和 |
| `ir_imax_sum_k` | $R=|\mathbf J_{max}-\sum\mathbf J_i|/K$，$i\ne max$ | 两绕组下可能退化，必须确认多绕组/逐相定义 |
| `ir_sqrt_cos` | $R=\sqrt{-AB\cos\delta}$ | 只有根号内非负才有实数意义 |
| `ir_sum_sq_cos` | $R=-AB\cos\delta$ | 通常配 `id_sum_sq` |
| `ir_diff_sq_cos` | $R=AB\cos\delta$ | 通常配 `id_diff_sq` |

### 3.4 建议允许的方程配对

| 动作式 | 建议制动式 | 说明 |
|---|---|---|
| `id_i1` | `ir_i2` | 两侧幅值直接给定，但相对角仍需独立约定；通常应限 2I |
| `id_sum` | `ir_diff_k`、`ir_sum_div_k`、`ir_max_k`、`ir_i2_k`、`ir_id_abs_diff`、`ir_sqrt_cos` | 每种必须用自己的原式求解并验算 |
| `id_diff` | `ir_sum_k`、`ir_sum_div_k`、`ir_max_k`、`ir_i2_k`、`ir_id_abs_diff` | `ir_sqrt_cos` 若要配合需另定反相分支 |
| `id_sum_sq` | `ir_sum_sq_cos` | 自然配对 |
| `id_diff_sq` | `ir_diff_sq_cos` | 自然配对 |
| 任意 | `ir_imax_sum_k` | 在取得其准确 N 绕组公式前不应启用 |

反配组合并不总能提供两个独立坐标。例如 `id_sum + ir_sum_k` 在 $\delta=180^\circ$ 时会得到 `R=D/K`，此时任意 `(D,R)` 并不可达。

## 4. 当前程序对比率点的实际计算

本章是对现有代码的精确描述，不代表推荐算法。

### 4.1 点值预处理

比率点先取：

```text
ratio-fixed:  R = point.x, D = point.y
ratio-search: R = point.x, D = 当前二分得到的 y
```

当前代码执行：

$$
(R_c,D_c)=
\begin{cases}
(R\,Ie,D\,Ie),&isPerUnit=true\\
(R,D),&isPerUnit=false
\end{cases}
$$

随后无条件：

$$
R_p=\sqrt2R_c,\qquad D_p=\sqrt2D_c
$$

再把 `Rp/Dp` 送入标量求解器。对线性齐次方程，这等价于最后把 RMS 结果乘 $\sqrt2$；对平方型方程则不等价。

### 4.2 当前标量求解器

令输入求解器的值为 `D/R`，下表中的 `a/b` 是除 Kp 前的量。

| 路由 | 当前计算 |
|---|---|
| `id_i1` | $a=D,\ b=R$；忽略 `irEquation` 和 K |
| `id_sum_sq/id_diff_sq` | $d=\sqrt D$；$b=(-d+\sqrt{d^2+4R})/2$；$a=d+b$；忽略实际 `irEquation` 和 K |
| 四个枚举 `ir_diff_k/ir_sum_k/ir_sum_div_k/ir_imax_sum_k` | $a=(D+KR)/2$；$b=(KR-D)/2$ |
| `ir_max_k` | $a=R/K$；$b=a-D$ |
| `ir_i2_k/ir_id_abs_diff` | $b=R/K$；$a=D+b$ |
| `ir_sqrt_cos` | $b=(-D+\sqrt{D^2+4R^2})/2$；$a=D+b$ |
| 其他或未知 `irEquation` | $a=D,\ b=R$ |

初始侧 2 角：

$$
\delta_0=
\begin{cases}
180^\circ,&id\_sum\text{ 或 }id\_sum\_sq\\
0^\circ,&其他
\end{cases}
$$

如果 `b<0`，当前代码执行：

$$
b\leftarrow|b|,\qquad \delta_0\leftarrow\delta_0+180^\circ
$$

最后：

$$
c_1=\frac a{Kp_1}\angle0^\circ,\qquad
c_2=\frac b{Kp_2}\angle\delta_0
$$

当前代码没有把求得的 `a/b/δ` 代回原始 `Id/Ir` 方程，所以非法组合也会继续生成波形。

### 4.3 6I 的 A/B/C 当前经验算法

A、B、C 不使用通用矩阵逆解，而是进入昂立单相经验表。输入为：

```text
c1, c2, lowClock, letter1, letter2,
phaseCorrection, zeroSequenceCorrection, testPhase
```

`highClock` 在这条路径完全不参与。

先以 A 相建立高、低侧三个复数通道：

$$
\mathbf H=[0,0,0]^T,\qquad \mathbf L=[0,0,0]^T
$$

定义：

$$
r=\lfloor lowClock/2\rfloor,\qquad
j=r\bmod3,\qquad
s=(-1)^r
$$

`lowClock` 对“普通侧 2 通道和符号”的精确映射为：

| lowClock | 侧内通道 j | 乘数 s |
|---:|---|---:|
| 0、1 | 第 1 相 | +1 |
| 2、3 | 第 2 相 | -1 |
| 4、5 | 第 3 相 | +1 |
| 6、7 | 第 1 相 | -1 |
| 8、9 | 第 2 相 | +1 |
| 10、11 | 第 3 相 | -1 |

混合 Y/D 分支还使用三个通道选择规则：

$$
p=\left\lfloor\frac{30L+60}{120}\right\rfloor\bmod3
$$

$$
n=\left\lfloor
\frac{((360-30L)\bmod360)+60}{120}
\right\rfloor\bmod3
$$

$$
L_{eff}=
\begin{cases}
12-L,&letter_1=d,\ letter_2=y\\
L,&其他
\end{cases}
$$

令 `k=floor(Leff/2) mod 2`。补偿附加通道为：

| phaseCorrection | k=0 | k=1 |
|---|---:|---:|
| `y-side` | 第 2 相 | 第 3 相 |
| `delta-side` | 第 3 相 | 第 2 相 |

- 侧 1 命中相位校正时，`p` 是侧 1 的 $\sqrt3c_1$ 所在相；
- 侧 2 命中相位校正时，`n` 是侧 2 的 $\sqrt3c_2$ 所在相；
- 上表给出的附加通道写入另一侧的反向相量。

对于正常的奇数 Y/D clock：

| lowClock | p | n |
|---:|---|---|
| 1 | A | A |
| 3 | B | C |
| 5 | B | C |
| 7 | C | B |
| 9 | C | B |
| 11 | A | A |

当前分支规则如下：

1. 无相位校正，或选择的校正类型与两侧字母都不匹配：
   - `H[0]=c1`；
   - 两侧字母相同时 `L[j]=s·c2`；
   - 两侧字母不同时 `L[0]=c2`。
2. 两侧字母相同且都匹配所选校正类型：
   - `H[0]=√3·c1`；
   - `L[j]=√3·s·c2`。
3. Y/D 或 D/Y，且侧 1 匹配校正类型：
   - 侧 1 由 `lowClock` 选择一个通道写 `√3·c1`；
   - 侧 2 写 `c2` 和另一个反向 `-c2`。
4. Y/D 或 D/Y，且侧 2 匹配校正类型：
   - 与上一条镜像；
   - 侧 2 一个通道写 `√3·c2`；
   - 侧 1 写 `c1` 和另一个反向 `-c1`。

若 `zeroSequenceCorrection` 为真，只要两侧中至少有一侧为 Y，代码会对每个“没有命中相位校正”的三相组执行：

```text
找到第一个非零通道 k；
把下一个通道 (k+1)%3 直接写成当前值的相反数。
```

因此当前实现可能对混合接线中的 D 侧也追加零序对消，这属于昂立经验表复刻，不是通用保护规则。

最后：

- A：通道不移动；
- B：高、低侧各自循环右移 1 相；
- C：高、低侧各自循环右移 2 相。

### 4.4 6I 的 AB/BC/CA/ABC 当前矩阵算法

多相先构造目标模板：

$$
\begin{aligned}
q_{AB}&=[1,-1,0]^T\\
q_{BC}&=[0,1,-1]^T\\
q_{CA}&=[-1,0,1]^T\\
q_{ABC}&=[1,e^{-j120^\circ},e^{j120^\circ}]^T
\end{aligned}
$$

$$
\mathbf T_1=c_1q_F,\qquad \mathbf T_2=c_2q_F
$$

每侧独立计算一个角度。若该侧字母匹配 `phaseCorrection`：

$$
\theta_1=wrap((12-highClock)30^\circ)
$$

$$
\theta_2=wrap(-(12-lowClock)30^\circ)
$$

若不匹配但该侧为 Y 且打开零序校正，取 `θ=0`；否则该侧为单位映射。

当前 M 矩阵是去零序矩阵：

$$
M(\theta)=\frac23
\begin{bmatrix}
\cos\theta&\cos(\theta+120^\circ)&\cos(\theta-120^\circ)\\
\cos(\theta-120^\circ)&\cos\theta&\cos(\theta+120^\circ)\\
\cos(\theta+120^\circ)&\cos(\theta-120^\circ)&\cos\theta
\end{bmatrix}
$$

输出规则：

- 单位映射：`I=T`；
- `θ=0` 且为多相：仍直接 `I=T`，因为这些模板本来就是三相和为 0；
- 其他角度：`I=M(-θ)T`。

这条路径按各侧自己的绝对 clock 算角，没有先使用两侧相对 clock。典型 `Y/d11 + y-side` 中，侧 1 的 `highClock=0` 导致 `θ1=0`，侧 2 D 又不匹配 Y 侧校正，于是 `lowClock=11` 对 AB/ABC 完全不起作用。这正是当前多相结果与单相昂立结果不一致的核心原因。

### 4.5 6I 结果落到物理通道

`compute_6ch` 返回顺序固定为：

```text
[side1-A, side1-B, side1-C, side2-A, side2-B, side2-C]
```

然后按端子映射：

```text
high-y -> Ia, Ib, Ic -> API 6,7,8
low-y  -> Ix, Iy, Iz -> API 9,10,11
```

如果 I1/I2 端子交换，两组三相也交换；如果两侧选择相同端子，I2 覆盖 I1。

## 5. 当前 2I 的实际计算

2I 复用第 4.2 节的标量 `a/b/δ0`，但后续规则与 6I 不一致。

### 5.1 幅值

先除 Kp。然后逐侧判断：

$$
gain_s=
\begin{cases}
\sqrt3,&phaseCorrection=y\text{-}side\ 且 letter_s=y\\
\sqrt3,&phaseCorrection=delta\text{-}side\ 且 letter_s=d\\
1,&其他
\end{cases}
$$

$$
I_{1,total}=gain_1\frac a{Kp_1},\qquad
I_{2,total}=gain_2\frac b{Kp_2}
$$

两个 clock、`zeroSequenceCorrection` 和 `testPhase` 全部忽略。

### 5.2 相角

当前 2I 固定：

$$
\phi_1=0^\circ,\qquad
\phi_2=wrap(180^\circ+\delta_0)
$$

所以在 `b≥0` 时：

| 动作式 | 6I 补偿域侧 2 角 | 2I 物理侧 2 角 |
|---|---:|---:|
| `id_sum` | 180° | 0° |
| `id_diff` | 0° | 180° |

除非 2I 外部接线本来就有固定反极性，否则这是需要确认的明确不一致。

### 5.3 并联通道

若端子映射到 N 个通道，当前每个通道输出：

$$
\mathbf I_{channel}=\frac{\mathbf I_{total}}N
$$

所有并联源相角相同。未选电流通道为 0。

## 6. 当前谐波项目的实际计算

谐波项目完全绕过 `solve()` 和 `compute_6ch()`，因此当前下列参数都不影响谐波输出：

- `idEquation/irEquation/kFactor/kp1/kp2`；
- 两侧 Y/D 和 clock；
- `phaseCorrection/zeroSequenceCorrection`；
- `diffMode/loadCurrent`。

### 6.1 幅值

取点：

```text
h = point.x
Id = point.y
```

若 `isPerUnit=true`，只有 `Id` 乘 `Ie`。然后：

$$
I_{1st,peak}=\sqrt2\,Id
$$

相对模式：

$$
I_{N,peak}=\frac h{100}\sqrt2\,Id
$$

绝对模式：

$$
I_{N,peak}=\sqrt2\,h
$$

### 6.2 6I 相别分配

`applySide=i1` 选择 I1 端子；任何其他字符串都静默选择 I2 端子。

| `testPhase` | 当前选中侧内通道 | 基波与谐波角 |
|---|---|---|
| A | A | 0° |
| B | B | -120° |
| C | C | +120° |
| AB | A、B | 0°、-120° |
| BC | B、C | -120°、+120° |
| CA | C、A | +120°、0° |
| ABC | A、B、C | 0°、-120°、+120° |

每个被选中的相都承载完整 `Id`，不是多相之间均分。谐波层使用与该相基波完全相同的相角。

### 6.4 谐波层与频率

- 基波写 layer 1；
- 谐波写 `layer=order`；

## 7. 建议采用的统一专业计算模型

### 7.1 不再直接从枚举拼凑六路电流

应先为每一台被测保护、每一组定值生成一个 `DUT Profile`。对侧 `s=1,2` 和第 N 次谐波定义：

$$
\boxed{\mathbf J_s^{(N)}
=Kp_s\,\mathbf C_s^{(N)}\,\mathbf W_s\,\mathbf I_{out,s}^{(N)}
=\mathbf A_s^{(N)}\mathbf I_{out,s}^{(N)}}
$$

其中：

- $\mathbf I_{out,s}$：测试仪真正要输出的三相复相量；
- $\mathbf W_s$：逻辑相到物理端子的排列、ABC/ACB 相序、CT 极性、外部 CT 接线；
- $\mathbf C_s$：被测保护内部真实使用的相位/零序补偿矩阵；
- `Kp_s`：保护内部幅值平衡系数；
- $\mathbf J_s$：真正进入保护 `Id/Ir` 方程的相量；
- $\mathbf A_s=Kp_s C_s W_s$：本次配置完整正向算子。

这样每个前端参数只负责生成 Profile 或目标相量，计算过程不需要再为 A、AB、Yd11 分散堆叠经验分支。

### 7.2 DUT Profile 至少需要保存的字段

现有简化参数可以继续作为前端输入，但后端必须把它们解析成明确 Profile：

```text
phaseSequence: ABC | ACB

side1 / side2:
    windingId
    windingLetter: y | d
    clock
    baseCurrent
    kp
    kpConvention: relay_multiplies | relay_divides
    matrixType: identity | preserve_zero | remove_zero | custom
    matrixAngle
    removeZeroSequence
    channelOrder
    polarity
    externalCtWiring

phaseTemplates:
    A, B, C, AB, BC, CA, ABC

equationProfile:
    exactIdFunction
    exactIrFunction
    validPairs

zeroSequenceProfile:
    mode: I0 | 3I0 | REF
    neutralTerminal
    neutralCtRatio
    neutralPolarity

incrementalMemoryMs

harmonicProfile:
    angleConvention
    crossBlocking
    compensationStage
```

如果当前 JSON 无法唯一解析为 Profile，应在开始前提示缺少哪一项，而不是使用默认矩阵继续发波。

### 7.3 保护补偿矩阵必须区分两类

独立去零序投影：

$$
P_0=I-\frac13\mathbf1\mathbf1^T
$$

旋转并去零序的矩阵：

$$
C_0(\theta)=\frac23
\begin{bmatrix}
\cos\theta&\cos(\theta+120^\circ)&\cos(\theta-120^\circ)\\
\cos(\theta-120^\circ)&\cos\theta&\cos(\theta+120^\circ)\\
\cos(\theta+120^\circ)&\cos(\theta-120^\circ)&\cos\theta
\end{bmatrix}
$$

保留零序的广义旋转矩阵：

$$
C(\theta)=\frac13
\begin{bmatrix}
1+2\cos\theta&1+2\cos(\theta+120^\circ)&1+2\cos(\theta-120^\circ)\\
1+2\cos(\theta-120^\circ)&1+2\cos\theta&1+2\cos(\theta+120^\circ)\\
1+2\cos(\theta+120^\circ)&1+2\cos(\theta-120^\circ)&1+2\cos\theta
\end{bmatrix}
$$

`C0` 的秩是 2，会消除零序；`C` 在 `θ=0` 时是单位阵并保留零序。当前程序只有 `C0` 这一族，不能代表所有保护配置。

相对钟点先计算：

$$
\Delta=wrap_{[-180^\circ,180^\circ)}
\left((highClock-lowClock)30^\circ\right)
$$

Yd11 的 `0-11` 得到 +30°。但 `Δ` 只是选择保护矩阵的依据，不能脱离保护说明书直接规定哪侧乘正角或负角。

例如在当前昂立单相样本所体现的 Yd11、Y 侧校正、ABC 相序约定下，可以建立一个 Profile：

$$
C_1=C_0(+30^\circ),\qquad C_2=I
$$

若保护选择 D 侧校正，可能是：

$$
C_1=I\text{ 或 }P_0,\qquad C_2=C_0(-30^\circ)
$$

准确正负号仍要用被测保护说明书和昂立六路黄金样本锁定。

## 8. 统一算法第一步：单位归一与精确标量反解

### 8.1 推荐的单位层

建议内部统一使用 RMS 复相量：

1. 前端点值若为工程安培，直接求解；
2. 若为标幺，在线性方程中先在标幺域求 `a/b`，随后乘 `Ie`；
3. 平方型点必须明确使用 `A²` 或 `pu²`，不能只把 `Id` 乘一次 `Ie`；
4. Kp 和矩阵逆解仍在 RMS 域进行；
5. 最后每个交流分量只乘一次 $\sqrt2$ 写 FPGA；
6. `params.statics` 已是幅度值时原样保留。

一次齐次方程从 RMS 转成幅度时，坐标乘 $\sqrt2$；二次齐次方程的坐标应乘 2。最安全的实现是始终在 RMS/标幺域完成方程求解，只转换最终的实际通道相量。

### 8.2 精确求解原则

对每个合法方程组合建立原始求值器：

$$
F_d(A,B,\delta),\qquad F_r(A,B,\delta)
$$

求解候选 `(A,B,δ)` 后必须验证：

$$
|F_d-D|\le\epsilon_d,\qquad
|F_r-R|\le\epsilon_r
$$

不允许未知组合回退为 `A=D、B=R`；不允许只把负的 B 机械取绝对值而不重新验算原式。

### 8.3 常用合法组合的完整闭式解

#### 8.3.1 `id_sum + ir_diff_k`

令 `S=KR`。

若 `D≤S`：

$$
A=\frac{D+S}{2},\qquad B=\frac{S-D}{2},\qquad\delta=180^\circ
$$

若 `D>S`：

$$
A=\frac{D+S}{2},\qquad B=\frac{D-S}{2},\qquad\delta=0^\circ
$$

两支都能同时满足原始动作和制动公式。

#### 8.3.2 `id_diff + ir_sum_k`

`D≤S` 时使用同相：

$$
A=\frac{D+S}{2},\qquad B=\frac{S-D}{2},\qquad\delta=0^\circ
$$

`D>S` 时使用反相：

$$
A=\frac{D+S}{2},\qquad B=\frac{D-S}{2},\qquad\delta=180^\circ
$$

`id_sum + ir_sum_k` 或 `id_diff + ir_diff_k` 并不是同一个求解问题。在上述基准相位下，两坐标会退化成同一相量模，只有 `D=KR` 时可行，而且解仍不唯一。

#### 8.3.3 `ir_sum_div_k`

令 `S=KR`。选用使动作式表现为 `|A-B|` 的基准极性，要求：

$$
S\ge D
$$

$$
A=\frac{S+D}{2},\qquad B=\frac{S-D}{2}
$$

`id_sum` 取 `δ=180°`，`id_diff` 取 `δ=0°`。若 `D>S`，该点在此共线约束下不可达，不能靠翻相继续使用同一个解。

#### 8.3.4 `ir_max_k`

按 `R=K·max(A,B)`，令：

$$
m=\frac RK
$$

完整可行域是：

$$
0\le D\le2m
$$

若 `D≤m`：

$$
A=m,\qquad B=m-D
$$

使用“差”极性：`id_sum` 取 180°，`id_diff` 取 0°。

若 `m<D≤2m`：

$$
A=m,\qquad B=D-m
$$

使用“和”极性：`id_sum` 取 0°，`id_diff` 取 180°。

`D>2m` 时无解。

#### 8.3.5 `ir_i2_k`

按 `R=KB`，选择侧 1 为较大侧：

$$
B=\frac RK,\qquad A=D+B
$$

`id_sum` 取 180°，`id_diff` 取 0°。也可以存在其他分支，但必须明确前端希望固定哪一侧。

#### 8.3.6 `ir_id_abs_diff`

按文档字面式，在 `A≥B` 且动作量化为 `D=A-B` 时：

$$
R=|D-A-B|=2B
$$

所以：

$$
B=\frac R2,\qquad A=D+\frac R2
$$

该公式没有 K。只有 `K=2` 时才与 `ir_i2_k` 的当前求解器相同。如果被测保护真实公式是 `(A+B-D)/K`，则应改成 `B=KR/2`；必须以保护说明书为准。

#### 8.3.7 `ir_sqrt_cos`

自然合法组合是 `id_sum` 且 `δ=180°`：

$$
D=A-B,\qquad R^2=AB
$$

$$
B=\frac{-D+\sqrt{D^2+4R^2}}2,\qquad A=D+B
$$

如果要与 `id_diff` 配合，必须显式选择反相支路，此时：

$$
D=A+B
$$

要求 `D≥2R`，并有：

$$
A=\frac{D+\sqrt{D^2-4R^2}}2,\qquad
B=\frac{D-\sqrt{D^2-4R^2}}2
$$

不能沿用当前同相结果，因为 `δ=0°` 会令 `-AB cosδ` 为负。

#### 8.3.8 平方型配套

`id_sum_sq + ir_sum_sq_cos` 取 180°；`id_diff_sq + ir_diff_sq_cos` 取 0°。

令：

$$
d=\sqrt D,\qquad P=R
$$

则：

$$
d=A-B,\qquad P=AB
$$

$$
B=\frac{-d+\sqrt{d^2+4P}}2,\qquad A=d+B
$$

这里 `D` 和 `R` 的量纲都是电流平方；标幺换算必须按平方基值处理。

#### 8.3.9 `id_i1 + ir_i2`

$$
A=D,\qquad B=R
$$

这两个公式没有约束 `δ`，必须由试验接线或项目约定补充相对角。若 6I 也允许该组合，还要另行定义怎样展开到三相；不能默认复用普通相差动模板。

#### 8.3.10 `ir_imax_sum_k`

在取得准确的 N 绕组聚合定义前不提供伪闭式解。两绕组下按字面可能退化成 `|A-B|/K`，使 `Id/Ir` 不再是两个独立坐标，不能并入普通 `(A+B)/K` 求解器。

## 9. 统一算法第二步：相别模板

若 C07 确认 `testPhase` 表示物理故障型，建议在保护补偿域定义：

$$
\begin{aligned}
q_A&=[1,0,0]^T,&q_B&=[0,1,0]^T,&q_C&=[0,0,1]^T\\
q_{AB}&=[1,-1,0]^T,&q_{BC}&=[0,1,-1]^T,&q_{CA}&=[-1,0,1]^T\\
q_{ABC}&=[1,e^{-j120^\circ},e^{j120^\circ}]^T
\end{aligned}
$$

模板统一按：

$$
\max_k|q_F[k]|=1
$$

标量解变成两侧目标：

$$
\mathbf T_1=Aq_F,\qquad
\mathbf T_2=Be^{j\delta}q_F
$$

### 9.1 单相与去零序矩阵

若某侧使用 `C0`，其输出范围只有三相和为 0 的向量。`qA/qB/qC` 不在该范围，不能直接伪逆后把残差忽略。

应为该 DUT Profile 显式定义可实现的单相差动环。对于已经由昂立单相样本确认的 Yd11、Y 侧 `C0(+30°)` 约定，可以使用：

$$
q_A^{loop}=[1,0,-1]^T
$$

$$
q_B^{loop}=[-1,1,0]^T
$$

$$
q_C^{loop}=[0,-1,1]^T
$$

这正是“高侧一个通道乘 $\sqrt3$、低侧两个通道反向输出”在保护内部形成的差动环。其他接线和其他保护厂家必须由其补偿矩阵或黄金样本生成对应模板。

## 10. 统一算法第三步：按 diffMode 生成故障前和故障后目标

定义 ABC 正相序负荷模板：

$$
p=[1,e^{-j120^\circ},e^{j120^\circ}]^T
$$

暂按 C16，把 `loadCurrent=L` 解释为侧 1 补偿域正序 RMS：

$$
\mathbf J_{pre,1}=Lp
$$

为使预故障差流为 0：

$$
\mathbf J_{pre,2}=
\begin{cases}
-Lp,&idEquation\text{ 为 sum 系}\\
+Lp,&idEquation\text{ 为 diff 系}
\end{cases}
$$

### 10.1 `diffMode=0`：稳态差动

建议状态定义：

```text
Node 1（如果启用）：
    J1 = Jpre,1
    J2 = Jpre,2

Node 2：
    J1 = T1
    J2 = T2
```

即故障态用目标测试电流替换负荷，不叠加 `loadCurrent`。

### 10.2 `diffMode=2`：工频变化量差动

把第 9 章的目标当作增量：

$$
\Delta\mathbf J_1=\mathbf T_1,\qquad
\Delta\mathbf J_2=\mathbf T_2
$$

状态为：

$$
\mathbf J_{fault,1}=\mathbf J_{pre,1}+\Delta\mathbf J_1
$$

$$
\mathbf J_{fault,2}=\mathbf J_{pre,2}+\Delta\mathbf J_2
$$

验算时必须用：

$$
\Delta\mathbf J_s=
\mathbf J_{fault,s}-\mathbf J_{pre,s}
$$

再计算 `Id/Ir`。这一模式应要求：

- `simulatePreFault=true`；
- `preFaultDuration` 大于被测保护记忆窗和输出稳定时间；
- Node 1、Node 2 使用连续相位基准，切换时不能意外重置相角。

### 10.3 `diffMode=1`：零序差动

此模式不能用 `zeroSequenceCorrection=true` 代替。

若它是两侧残流比较，可以建立独立零序模型。必须先区分：

- 点值表示每相零序分量 `I0` 时，模板为 `[1,1,1]`；
- 点值表示残流 `3I0` 时，模板为 `[1,1,1]/3`；
- REF 中性点电流 `IN` 又是另一种量，不能与前两者混用。

可统一写成：

$$
J_{0,s}=Z_s\mathbf I_{out,s}
$$

若它是 REF/限制接地故障，还需要：

- 中性点 CT 物理通道；
- 中性点 CT 变比和极性；
- 相电流与中性点电流的动作/制动方程；
- 对应端子映射。

现有协议没有这些信息时，应在开始前返回“配置不足”，不能猜测六路相电流。

## 11. 统一算法第四步：反算 6I 和 2I 物理输出

### 11.1 6I

对每一个状态、每一侧求：

$$
\mathbf A_s\mathbf I_{out,s}=\mathbf J_s
$$

若 `A` 满秩：

$$
\mathbf I_{out,s}=\mathbf A_s^{-1}\mathbf J_s
$$

若 `A` 秩亏：

$$
\mathbf I_{out,s}=
\mathbf A_s^+\mathbf J_s+
(I-\mathbf A_s^+\mathbf A_s)\mathbf z_s
$$

其中 `A+` 是 Moore-Penrose 伪逆。对于去零序矩阵，零空间通常包含：

$$
z[1,1,1]^T
$$

可以在不改变保护补偿后结果的前提下选择 `z`，目标依次为：

1. 保证精确可达；
2. 最小化六路中的最大峰值；
3. 不超过每个功放通道量程；
4. 优先得到稀疏输出；
5. 在等价解中尽量与昂立显示一致。

发波前必须检查可达残差：

$$
\left\|(I-\mathbf A_s\mathbf A_s^+)\mathbf J_s\right\|\le\epsilon
$$

残差超限时不得输出“最接近”的错误波形。

### 11.2 2I

2I 不应再仅按字母乘 $\sqrt3$。为每侧建立一个明确复数增益：

$$
J_s=g_s I_{total,s}
$$

`g_s` 必须统一包含：

- Kp；
- 外部 CT/端子极性；
- 必要的 $\sqrt3$；
- clock 相移；
- 保护内部相位补偿。

于是：

$$
I_{total,s}=\frac{J_s}{g_s}
$$

只有 C18 确认多个电流源确实并联到同一个保护端子时，才执行：

$$
I_{channel}=\frac{I_{total,s}}N
$$

否则应回到多相模型，不做同相均分。

### 11.3 端子映射

得到两侧物理相量后：

1. 按 `i1Terminal` 把侧 1 映射到 Ia/Ib/Ic 或 Ix/Iy/Iz；
2. 按 `i2Terminal` 映射侧 2；
3. 检查两侧通道集合不相交；
4. 未使用的电流通道明确置 0；
5. 保留本次规定的实际基波频率。

## 12. 统一谐波计算

若谐波项目模拟单侧励磁涌流，先在保护补偿域定义施加侧的基波：

$$
\mathbf J_{apply}^{(1)}=I_{base}q_F
$$

另一侧为 0。

相对谐波：

$$
H=\frac h{100}I_{base}
$$

绝对谐波：

$$
H=h
$$

再定义：

$$
\mathbf J_{apply}^{(N)}
=H e^{j\phi_N}q_{F,N}
$$

如果要模拟真实三相 N 次谐波，其相序模板应为：

$$
q_{ABC,N}=
[1,e^{-jN120^\circ},e^{jN120^\circ}]^T
$$

它会随 N 对 3 取模表现为正序、负序或零序。若实验只是对保护某一差动元件注入同相谐波，则 `qF,N` 应由 DUT Profile 明确给出，不能自动套上述电网模板。

每一层分别逆解：

$$
\mathbf I_{out,s}^{(N)}
=(\mathbf A_s^{(N)})^+\mathbf J_s^{(N)}
$$

然后：

- 基波 RMS 乘 $\sqrt2$ 写 layer 1；
- N 次谐波 RMS 乘 $\sqrt2$ 写 layer N；
- 基波频率设为 `frequency`；
- 验证 FPGA 的 layer N 实际为 `N×frequency`；
- 不只检查每层幅度，还要检查各层叠加后的最大瞬时电流不超过功放范围。

在 C20～C23 未确认前，当前谐波算法只能视为简化注入，不能与统一 6I 补偿算法混为一体。

---

## 13. 写 FPGA 前必须执行的正向验算

对算出的每个状态重新执行保护正向模型：

$$
\widehat{\mathbf J}_s
=\mathbf A_s\mathbf I_{out,s}
$$

然后：

1. 稳态差动：用 Node 2 的 `J1/J2` 计算实际 `Id/Ir`；
2. 工频变化量：用 Node 2 减 Node 1 的 `ΔJ1/ΔJ2` 计算；
3. 零序差动：用独立 `Z` 模型计算；
4. 对每个参与相按原始 `idEquation/irEquation` 求 `Id_actual/Ir_actual`；
5. 检查目标相误差；
6. 检查非目标相是否可能先动作；
7. 检查全部复数、幅值和角度为有限值；
8. 检查每通道 RMS、单层幅度和叠加瞬时峰值；
9. 检查并联源之和等于目标总电流；
10. 检查端子没有重叠覆盖。

任一步失败都应在放大器输出目标波形前终止该点并报告配置错误。

最后的编码步骤才是：

$$
I_{peak}^{(N)}=\sqrt2\,I_{RMS}^{(N)}
$$

把负的复相量转换成“正幅值 + 相角加 180°”，再写成：

```json
{
  "6": {
    "1": [1.4142, 0.0],
    "2": [0.2828, 30.0]
  }
}
```

报告应返回：

- 目标与正向验算得到的 `Id/Ir`；
- 补偿域 `A/B/δ`；
- 六路物理 RMS；
- 六路最终写入 FPGA 的幅度和角度；
- 采用的 DUT Profile/矩阵标识。

当前固定读取物理 Ia 和 Ix 作为 `report.i1/i2` 的方法不适用于 B/C、多相、换相或稀疏逆解。

## 14. Yd11、Y 侧校正的计算示例

本例只用于展示完整计算链，前提是 C02、C05、C07、C09～C12 按本文暂定口径确认。

设置：

```text
Id = 0.5 A RMS
Ir = 1.0 A RMS
K = 2
Kp1 = Kp2 = 1
idEquation = id_sum
irEquation = ir_diff_k
Y/d11，Y侧校正
C1 = C0(+30°)，C2 = I
```

标量解：

$$
A=\frac{0.5+2\times1}{2}=1.25\ A

$$
B=\frac{2\times1-0.5}{2}=0.75\ A

$$
\delta=180^\circ
$$

$$
q_A^{loop}=[1,0,-1]^T

$$
\mathbf I_1=[\sqrt3A,0,0]^T
=[2.1651,0,0]^T

$$
\mathbf I_2=[-B,0,+B]^T
=[-0.75,0,+0.75]^T

| Iy | 0 | 0 |

### 14.2 AB 相间故障

q_{AB}=[1,-1,0]^T

\mathbf I_1=A\,C_0(-30^\circ)q_{AB}

## 15. 建议的最终实现顺序

```text
1. parse_and_validate_json()
2. resolve_dut_profile()
      -> 原始Id/Ir公式
      -> 相别模板
      -> A1/A2 或 2I 的 g1/g2
      -> 相序、端子与极性
3. normalize_point_units()
4. solve_exact_id_ir()
5. build_phase_target()
6. build_pre_and_fault_states(diffMode, loadCurrent)
7. inverse_to_physical_currents()
8. add_harmonic_components_if_needed()
9. forward_validate_every_equation()
10. validate_channel_mapping_and_limits()
11. convert_rms_to_fpga_amplitude_once()
12. build_Node1_and_Node2()
13. report_protection_domain_and_physical_results()
```

任何步骤遇到以下情况都应明确拒绝，而不是静默回退：

- 未知枚举或非法方程配对；
- K、Kp、Ie 非法或为 0；
- clock 超出 0～11；
- 端子重叠；
- 相别模板不在补偿矩阵值域；
- 方程无解或退化成无限解；
- 缺少零序/REF 所需通道；
- 工频变化量没有可控预故障状态；
- 六路或多谐波叠加超过功放能力。

## 16. 当前代码与目标算法的差异清单

| 项目 | 当前程序 | 目标算法 |
|---|---|---|
| 参数校验 | 大量默认和静默回退 | 非法组合在发波前拒绝 |
| 单位 | 点值无条件乘 $\sqrt2$ 后求解 | RMS 域求解，最后只转换一次 |
| 平方型标幺 | 仍只乘 `Ie` | 按 `Ie²` 和实际量纲处理 |
| 方程 | 多个 Ir 枚举共用公式 | 每个原式独立求解并正向验算 |
| 单相/多相 | 两套算法 | 同一 Profile 和逆解框架 |
| clock | 单相丢 high，多相按绝对 clock | 先识别两侧相对关系，再选择真实保护矩阵 |
| Kp | 标量阶段直接除 | 纳入完整正向算子，避免重复补偿 |
| `diffMode` | 未使用 | 分别构造稳态、零序、变化量状态 |
| `loadCurrent` | 未使用 | 构造穿越负荷和变化量基准 |
| 2I | 只按 Y/D 乘 $\sqrt3$ | 用明确复数连接增益 |
| 谐波 | 绕过全部补偿 | 每个谐波层单独正向/逆向建模 |
| 频率 | 固定沿用 50 Hz | 使用项目 frequency 并验证 N 倍频率 |
| 报告 | 固定取 Ia/Ix | 返回补偿域结果和真实六路 |

## 17. 下一步需要你的确认

请优先对第 1 章 C01～C23 给出修改意见。确认后才能把“暂定理解”变成最终协议，并据此：

1. 整理合法 `idEquation × irEquation` 配对表；
2. 为每种接线配置建立 DUT Profile；
3. 用昂立 A、AB、ABC 六路结果作为黄金样本；
4. 再制定或实施代码改造。

本文没有把“昂立单相经验表”直接外推成多相真值。专业上可靠的标准是：生成六路以后，用同一个保护正向模型重新算出的 `Id/Ir` 必须与前端目标一致，并且昂立和实际被测保护的补偿后测量量也一致。
