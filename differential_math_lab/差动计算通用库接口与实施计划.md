# 差动计算通用库接口与实施计划

## 1. 最终目标

本模块是一个独立的 `double` 浮点数学核心，只完成下面的变换：

```text
保护内部目标三相 Peak 复电流
              ↓
       补偿矩阵反变换
              ↓
测试仪逻辑侧三相 Peak 输出电流的完整解空间
```

公开的主要计算函数只有：

```python
calcOutputSolution(profile, targetCurrent)
```

Python 原型使用 `float`；移植到 C/C++ 时对应 `double`。数学核心不主动模拟 DAC、FPGA 或输出板卡的有限精度。

## 2. 本库不负责的内容

以下内容必须由上层试验逻辑、保护型号适配层或硬件适配层完成：

- 差动电流 $I_d$ 的定义；
- 制动电流 $I_r$ 的定义；
- 动作方程、制动方程和其中的系数 $K$；
- A、B、C、AB、BC、CA、ABC 等试验相别模板；
- 比率差动边界搜索、动作值搜索和动作时间流程；
- 谐波比例和谐波闭锁目标的生成；
- 故障前负荷、故障量和增量量的合成；
- 根据 Y/D 绕组、钟点号、Y 侧或 D 侧校正推断矩阵号；
- CT 极性、相序、通道交换和实际硬件通道映射；
- RMS 与 Peak 之间的转换；
- FPGA 寄存器、DAC 码值及其他硬件量化。

因此，本库既不会固定某一种 $I_d/I_r$ 公式，也不会因为前端增加新的制动方程而变化。

## 3. 分层边界

建议完整调用链保持为：

```text
前端 API 参数
    ↓
试验公式层：根据 Id、Ir、K、相别等生成 J1/J2
    ↓
保护 Profile Adapter：确定 matrix1、matrix2、kp1、kp2
    ↓
DiffCalc.calcOutputSolution()
    ↓
上层从完整解空间中选择公共模 c
    ↓
通道适配层：极性、排列、RMS/Peak、量程和硬件量化
    ↓
实际电流输出通道
```

`DiffCalc.py`只占其中的矩阵反变换步骤。

## 4. Peak 直角复相量

核心相量定义为：

$$
\hat I=I_{re}+jI_{im}
$$

其中 `re` 和 `im` 都是 Peak 复幅值。对应真实瞬时波形为：

$$
i(t)=\operatorname{Re}\left\{\hat I e^{j\omega t}\right\}
$$

代码结构为：

```python
@dataclass(frozen=True)
class Phasor:
    re: float
    im: float
```

本模块不接收“幅值 + 相角”，也不调用 `atan2()`。如果前端使用 Peak 幅值 $I_p$ 和相角 $\varphi$，上层应先计算：

$$
I_{re}=I_p\cos\varphi
$$

$$
I_{im}=I_p\sin\varphi
$$

如果某个界面参数是 RMS，上层必须在进入本库前完成一次 RMS 到 Peak 的转换：

$$
I_{peak}=\sqrt{2}I_{rms}
$$

不要在本库内部再次乘或除 $\sqrt{2}$。

## 5. 显式保护 Profile

数学核心只接收四个保护内部参数：

```python
@dataclass(frozen=True)
class DiffProfile:
    matrix1: int
    matrix2: int
    kp1: float
    kp2: float
```

含义如下：

| 字段 | 含义 |
|---|---|
| `matrix1` | 绕组侧 1 在保护内部实际使用的矩阵号，范围 0～12 |
| `matrix2` | 绕组侧 2 在保护内部实际使用的矩阵号，范围 0～12 |
| `kp1` | 侧 1 的保护内部电流平衡系数，必须为有限正数 |
| `kp2` | 侧 2 的保护内部电流平衡系数，必须为有限正数 |

Yd11、Yy12 等接线组别只能描述变压器名义相移，不能唯一确定保护软件最终使用的矩阵。保护厂家、型号、固件、CT 接线以及校正位置都可能改变矩阵组合。

因此，下面的转换不属于本库：

```text
Yd11 + Y侧校正 + 零序设置
                    ↓
             matrix1 / matrix2
```

该转换应由外部 `relay/vendor profile adapter` 根据被测保护的说明书和现场验证结果完成。

例如，已经用于解释特定兼容试验的 `M1/M0` 或 `M11/M11` 只能作为相应保护 Profile 的明确配置，不能写成所有 Yd11 或 Yy12 的通用推断规则。

## 6. 输入目标

`targetCurrent`严格表示两个绕组侧，每侧三个保护内部目标相量：

```python
targetCurrent = (
    (J1A, J1B, J1C),
    (J2A, J2B, J2C),
)
```

其中：

```text
targetCurrent[0] = 侧1保护内部目标 [J1A, J1B, J1C]
targetCurrent[1] = 侧2保护内部目标 [J2A, J2B, J2C]
```

六个元素都必须是 `Phasor`，并且每个 `re/im` 都必须是有限实数。NaN、正负无穷以及错误的 `2 × 3` 形状都会被拒绝。

目标 $\mathbf J_1$ 和 $\mathbf J_2$ 如何由 $I_d/I_r$、相别和动作方程得到，是上层职责。

## 7. 正向保护模型

每一侧统一采用：

$$
\boxed{\mathbf J=K_p\mathbf M\mathbf X}
$$

其中：

- $\mathbf J$：保护内部希望看到的三相 Peak 复电流；
- $\mathbf X$：测试仪在该逻辑绕组侧应输出的三相 Peak 复电流；
- $K_p$：该侧的保护内部电流平衡系数；
- $\mathbf M$：该侧明确指定的 M0～M12 补偿矩阵。

正向模型在代码和未来 C/C++ 接口中统一写成这一种顺序，不再同时使用其他等价写法，避免实现说明产生歧义。

## 8. 标准矩阵 M0～M12

### 8.1 M0

M0 是单位阵：

$$
\mathbf M_0=
\begin{bmatrix}
1&0&0\\
0&1&0\\
0&0&1
\end{bmatrix}
$$

M0 不消除公共零序，矩阵满秩。

### 8.2 M1～M12

令：

$$
\theta_n=n\times30^\circ
$$

标准矩阵定义为：

$$
\mathbf M_n=\frac{2}{3}
\begin{bmatrix}
\cos\theta_n&\cos(\theta_n+120^\circ)&\cos(\theta_n-120^\circ)\\
\cos(\theta_n-120^\circ)&\cos\theta_n&\cos(\theta_n+120^\circ)\\
\cos(\theta_n+120^\circ)&\cos(\theta_n-120^\circ)&\cos\theta_n
\end{bmatrix}
$$

代码将 M0～M12 保存成冻结的 `float` 常量表 `MATRIX_TABLE`，运行时不计算 `sin()` 或 `cos()`。

对 M1～M12：

$$
\mathbf M_n
\begin{bmatrix}
1\\1\\1
\end{bmatrix}=0
$$

因此这些矩阵秩为 2，并消除三相公共零序。

### 8.3 M0 与 M12 不相同

虽然钟点 0 和钟点 12 在角度上等价，但本库的编号语义是：

```text
M0  = 单位阵，不消除零序
M12 = 0°旋转的零序消除矩阵
```

所以必须始终满足：

$$
\boxed{\mathbf M_0\ne\mathbf M_{12}}
$$

矩阵号不得通过 `% 12` 处理，否则 M12 会被错误映射成 M0。

## 9. M0 的唯一解

当 `matrixNumber == 0` 时：

$$
\mathbf J=K_p\mathbf X
$$

因此唯一解为：

$$
\boxed{\mathbf X=\frac{\mathbf J}{K_p}}
$$

返回：

```text
base      = J / Kp
hasCommon = False
```

M0 对输入目标没有三相和为零的限制。

## 10. M1～M12 的可达性

因为 M1～M12 的输出一定不含公共零序，目标必须位于矩阵值域中：

$$
\boxed{J_A+J_B+J_C=0}
$$

实部和虚部必须分别满足：

$$
J_{A,re}+J_{B,re}+J_{C,re}=0
$$

$$
J_{A,im}+J_{B,im}+J_{C,im}=0
$$

浮点可达性使用相对目标幅值的容差。实部和虚部分别计算尺度：

```python
EPS = 1e-12

reScale = max(1.0, abs(JA.re), abs(JB.re), abs(JC.re))
imScale = max(1.0, abs(JA.im), abs(JB.im), abs(JC.im))

abs(sumRe) <= EPS * reScale
abs(sumIm) <= EPS * imScale
```

分别取尺度可以避免实部和虚部相互放宽容差；`max(1.0, ...)` 则保留小信号附近的绝对容差下限。这样同一个理论零和目标整体放大后，不会仅因 `double` 舍入误差而被误判为不可达。

如果任意一项不满足，函数返回 `UNREACHABLE_TARGET`，绝不把伪逆投影结果冒充为目标的合法解。

例如：

```text
[1, -1, 0]  可达
[1, 0, 0]   不可达
```

## 11. M1～M12 的基准解

标准 M1～M12 满足：

$$
\mathbf M^+=\mathbf M^T
$$

其中 $\mathbf M^+$ 是 Moore-Penrose 伪逆。因此最小范数基准解为：

$$
\boxed{\mathbf X_0=\frac{\mathbf M^T\mathbf J}{K_p}}
$$

函数返回的 `base` 就是 $\mathbf X_0$。

## 12. 完整解空间

由于 M1～M12 消除公共零序，其零空间为：

$$
\operatorname{null}(\mathbf M)=
\operatorname{span}
\left\{
\begin{bmatrix}1\\1\\1\end{bmatrix}
\right\}
$$

所以完整解空间是：

$$
\boxed{
\mathbf X=
\mathbf X_0+
c\begin{bmatrix}1\\1\\1\end{bmatrix},
\qquad c\in\mathbb C
}
$$

返回：

```text
base      = X0
hasCommon = True
```

函数不选择 $c$。上层可根据实际需要选择：

- `c = 0`：最小范数基准解；
- 让某一路电流为 0：稀疏输出；
- 最小化最大通道 Peak；
- 避开某个不可用电流源；
- 满足设备每路最大输出范围。

选择 $c$ 后，上层还必须检查所有最终通道是否有限并处于硬件允许范围内。

## 13. 正向 residual

函数对基准解执行正向回算：

$$
\hat{\mathbf J}=K_p\mathbf M\mathbf X_0
$$

并返回：

$$
\boxed{\mathbf r=\hat{\mathbf J}-\mathbf J}
$$

每一侧的返回结构为：

```python
@dataclass(frozen=True)
class SideSolution:
    base: tuple[Phasor, Phasor, Phasor]
    hasCommon: bool
    residual: tuple[Phasor, Phasor, Phasor]
```

`residual`只用于诊断矩阵方向、Kp、输入模板和浮点实现是否闭合。正常 `double` 舍入产生的极小残差不会改变 `status=OK`。

本库不提供 `maxResidual`，也不定义与硬件分辨率相关的误差阈值。调用方如果有验收精度要求，应在自己的测试或硬件适配层判断。

## 14. 状态码

```python
class CalcStatus(IntEnum):
    OK = 0
    INVALID_CONFIG = 1
    INVALID_TARGET = 2
    UNREACHABLE_TARGET = 3
    NUMERIC_ERROR = 4
```

| 状态 | 含义 |
|---|---|
| `OK` | 两侧均成功得到解空间 |
| `INVALID_CONFIG` | 矩阵号非法，或 Kp 非有限、非正数 |
| `INVALID_TARGET` | 输入不是严格的 2×3 `Phasor`，或某个分量不是有限数 |
| `UNREACHABLE_TARGET` | 某个 M1～M12 目标不满足三相复数和为零 |
| `NUMERIC_ERROR` | 合法有限输入在计算中产生非有限结果 |

`failedSide`语义为：

```text
0 = 全局配置或整体输入结构错误
1 = 侧1失败
2 = 侧2失败
```

侧 2 失败时，已经成功计算的 `side1` 可以保留用于诊断。

## 15. 最终公开 API

模块的 `__all__` 只包含：

```python
Phasor
DiffProfile
CalcStatus
SideSolution
OutputSolution
calcOutputSolution
```

调用示例：

```python
from DiffCalc import DiffProfile, Phasor, CalcStatus, calcOutputSolution

profile = DiffProfile(
    matrix1=1,
    matrix2=0,
    kp1=1.0,
    kp2=1.0,
)

target = (
    (Phasor(1.25, 0.0), Phasor(-1.25, 0.0), Phasor(0.0, 0.0)),
    (Phasor(-0.75, 0.0), Phasor(0.75, 0.0), Phasor(0.0, 0.0)),
)

result = calcOutputSolution(profile, target)

if result.status == CalcStatus.OK:
    print(result.side1.base)
    print(result.side1.hasCommon)
    print(result.side1.residual)
    print(result.side2.base)
    print(result.side2.hasCommon)
    print(result.side2.residual)
```

## 16. 核心算法流程

单侧计算流程如下：

```text
检查 matrixNumber 和 Kp
        ↓
检查三相 Phasor 及有限性
        ↓
M1～M12：检查 JA + JB + JC ≈ 0
        ↓
M0：       X0 = J / Kp
M1～M12： X0 = transpose(M) × J / Kp
        ↓
正向回算 Jhat = Kp × M × X0
        ↓
residual = Jhat - J
        ↓
返回 base、hasCommon、residual
```

矩阵乘法分别作用于复相量的实部和虚部，不需要复数矩阵系数：

$$
X_{i,re}=\sum_j M_{ji}J_{j,re}
$$

$$
X_{i,im}=\sum_j M_{ji}J_{j,im}
$$

## 17. C/C++ 双精度接口计划

Python 版本稳定后，C/C++ 版本建议采用等价的简单结构：

```c
typedef struct {
    double re;
    double im;
} Phasor;

typedef struct {
    int matrix1;
    int matrix2;
    double kp1;
    double kp2;
} DiffProfile;

typedef struct {
    Phasor base[3];
    int hasCommon;
    Phasor residual[3];
} SideSolution;
```

DLL 只需要一个导出计算入口。状态码作为函数返回值，结果通过输出参数返回，例如：

```c
CalcStatus calcOutputSolution(
    const DiffProfile *profile,
    const Phasor targetCurrent[2][3],
    OutputSolution *result
);
```

C/C++ 版本必须与 Python 使用相同的：

- M0～M12 常量表；
- 矩阵方向；
- Peak 直角复相量定义；
- 实部、虚部分别按目标幅值缩放的 `EPS = 1e-12` 可达性规则；
- 状态码数值；
- `failedSide` 语义。

## 18. 硬件量化的独立位置

当前通用数学核心不包含任何 Q 格式、整数移位、饱和或寄存器域换算。

如果未来需要支持纯 FPGA 或没有 FPU 的特殊 MCU，应建立独立实现，例如：

```text
DiffCalcDouble     通用参考实现，Python float / C double
DiffCalcFixed      特殊目标的定点实现
```

定点版本必须使用 `DiffCalcDouble` 生成黄金向量，并单独规定：

- 输入和输出缩放；
- 系数量化；
- 舍入规则；
- 饱和规则；
- 中间累加位宽；
- 最大允许误差。

这些规则不能反向污染通用数学核心。

## 19. 测试要求

`tests/test_diffcalc.py`覆盖：

1. M0 对任意目标给出唯一解；
2. 冻结矩阵表逐元素符合标准 M0～M12 定义；
3. M1 对 `[1,-1,0]` 正确反解并闭环；
4. M1 拒绝不可达目标 `[1,0,0]`；
5. ABC 正序目标通过 M1～M12；
6. 放大到 $10^6$ 的 ABC 正序目标不会被固定绝对容差误拒绝；
7. 超过相对容差的真实非零和目标仍会被拒绝；
8. M1～M12 添加多个随机复公共模后，正向目标不变；
9. 两侧使用不同且非 1 的 Kp 时仍闭环；
10. M0 与 M12 的值域和 `hasCommon` 行为不同；
11. 非法矩阵号、非正 Kp、NaN、Inf 和错误输入形状被拒绝；
12. 非有限计算结果返回 `NUMERIC_ERROR`；
13. 大量随机零和复目标的正向 residual 只处于 `double` 舍入量级；
14. 核心源码不再含定点缩放、整数位宽和定点舍入逻辑；
15. `__all__` 与最终六个公开符号保持一致。

## 20. 当前实施结论

最终核心的职责可以概括为：

$$
(\mathbf J_1,\mathbf J_2,\mathbf M_1,\mathbf M_2,K_{p1},K_{p2})
\longrightarrow
(\mathcal S_1,\mathcal S_2)
$$

其中：

$$
\mathcal S_s=
\begin{cases}
\left\{\mathbf J_s/K_{ps}\right\},&M_s=M_0\\
\left\{\mathbf M_s^T\mathbf J_s/K_{ps}+c\mathbf1\mid c\in\mathbb C\right\},&M_s=M_1\ldots M_{12}
\end{cases}
$$

这一个函数已经覆盖通用反变换所需的全部数学职责。任何 $I_d/I_r$ 公式变化只会改变上层生成的目标 $\mathbf J_1/\mathbf J_2$，不会改变本库。
