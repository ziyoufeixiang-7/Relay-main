# 6I 成品仪器计算结果参考数据（完整穷举版）

> **测试条件**: A 相差动, i1 = 1, i2 = -1（负号表示 180°）
> **未列出的通道均为 0**
> **clock 规则**: 所有配置 highClock = 0, lowClock = 表中数字（12 等价于 0）

## 规律总结

### 1. 无补偿 (§1)
- YY/DD: 侧1 固定 ia=1; 侧2 随 lowClock 旋转（每 2 步换通道，符号交替）
- YD/DY: 所有 clock 均 ia=1, ix=-1（clock 无影响）

### 2. Y 侧零序 (§2)
- 在无补偿基础上，每个 Y 侧非零通道追加**下一通道取反**
- D 侧不受影响

### 3. Y 侧校正 (§3)
- YY: 无补偿 × √3
- DD: 无补偿（D 不匹配 Y 侧校正）
- YD: 高侧 (Y) 一个通道 ×√3 + 低侧 (D) 固定 ix=-1 + 补偿通道
- DY: YD 的镜像（互换取反）

### 4. D 侧校正 (§4)
- DD: 无补偿 × √3
- YY: D 侧校正无效 → 等于无补偿；若叠加 zeroSeq=true → 等于 §2
- YD: 高侧 (Y) 零序对消 + 低侧 (D) 一个通道 ×√3
- DY: YD 的镜像（互换取反）
