# 自动校准数学推导与计算文档

> 本文档定义新架构 `AutoCal` 模块的校准算法。所有公式、符号约定与新代码 `Calibration.py` + `FPGACodec.py` 完全对齐。

---

## 核心原则

**所有拟合都在物理值空间进行**：

- FPGA DDS reg 值 → 转换为**物理值**作为拟合自变量 $x$
- 万用表采样均值 → 直接作为拟合因变量 $y$（DC 读数是幅度物理值，AC 读数是有效值物理值）
- 拟合得到物理增益 $G$ 和物理零偏 $O$，再推导校准系数

---

## 1. 预计算常量

### 1.1 缩放因子

$$S_V = \frac{32767}{200} = 163.835 \quad\text{(每伏对应的 reg 步长)}$$

$$S_I = \frac{32767}{60} = 546.11\overline{6} \quad\text{(每安培对应的 reg 步长)}$$

### 1.2 物理值 → reg 值 → 物理值 的转换

由于 reg 是 16 位整数，存在四舍五入量化误差，转换公式为：

$$\text{reg}_{16} = \text{round}(v_{input} \cdot S) \tag{1}$$

$$v_{actual} = \frac{\text{reg}_{16}}{S} \tag{2}$$

$v_{actual}$ 是 FPGA **实际输出的物理值**（量化后），与 $v_{input}$ 存在微小差异。**拟合时必须使用 $v_{actual}$**。

对于交流信号，reg 存储的是**峰值幅度**，需要转换为 RMS 物理值以与万用表读数对齐：

$$v_{actual,rms} = \frac{\text{reg}_{16}}{S \cdot \sqrt{2}} \tag{3}$$

## 3. 校准流程与数据采集

### 3.1 测量步骤（固定顺序，固定值不可修改）

| 步骤 | 信号 | Layer | 等待稳定 | 采样时长 |
|:----:|:----:|:-----:|:-------:|:-------:|
| ① AC | 电压 57.735V RMS / 电流 0.5A RMS | Layer1 | 5s | 电压 **10s** / 电流 **30s** |
| ② DC 零 | 0V / 0A | Layer0 | 5s | 电压 **10s** / 电流 **30s** |
| ③ DC + | +100V / +0.5A | Layer0 | 5s | 电压 **10s** / 电流 **30s** |
| ④ DC - | -100V / -0.5A | Layer0 | 5s | 电压 **10s** / 电流 **30s** |

### 3.2 每步执行时序

```
① FPGA 复位 + 全通道清零
② 万用表切换挡位/量程
③ FPGA 发送 DDS 帧（原始 reg 值，不经过校准因子）
④ 等待功放稳定 5s
⑤ 万用表连续采样（电压 10s / 电流 30s）
⑥ 计算采样均值 ȳ 和方差 σ²
⑦ FPGA 复位 + 全通道清零
```

### 3.3 采样统计

$N$ 个万用表读数 $\{z_1, z_2, \ldots, z_N\}$：

$$\bar{y} = \frac{1}{N}\sum_{k=1}^{N} z_k \tag{4}$$

$$\sigma^2 = \frac{1}{N}\sum_{k=1}^{N} (z_k - \bar{y})^2 \tag{5}$$

> **Shunt 模式**：$z_k = V_{dmm} / 0.075$（先折算为电流再统计）

### 3.4 采集后数据汇总

四步测量完成后，得到以下数据（**全部为物理值**）：

| 数据 | 自变量 $x$（FPGA reg 转物理值） | 因变量 $y$（万用表物理值） | 方差 |
|:----:|:--:|:--:|:--:|
| AC | $x_{ac}$（§2 预计算 RMS） | $\bar{y}_{ac}$（万用表 AC RMS 读数） | — |
| DC 零 | $x_0 = 0$ | $\bar{y}_0$（万用表 DC 读数） | $\sigma_0^2$ |
| DC + | $x_+$（§2 预计算幅度值） | $\bar{y}_+$（万用表 DC 读数） | $\sigma_+^2$ |
| DC - | $x_-$（§2 预计算幅度值） | $\bar{y}_-$（万用表 DC 读数） | $\sigma_-^2$ |

> $x$ 和 $y$ 在同一物理量空间：DC 都是幅度值 (V/A)，AC 都是 RMS 有效值 (V/A)。

## 4. 直流拟合：三点 WLS

### 4.1 物理模型

FPGA + 功放链路的直流传递函数：

$$y = G_{dc} \cdot x + O_{dc} \tag{6}$$

- $G_{dc}$：直流增益（物理值到物理值）
- $O_{dc}$：直流零偏（物理值）

### 4.2 WLS 权重

$$w_i = \frac{1}{\sigma_i^2 + 10^{-12}} \tag{7}$$

### 4.3 加权累计和

由于 $x_0 = 0$，含 $x_0$ 的乘积项为零：

$$W = w_+ + w_- + w_0$$

$$S_x = w_+ x_+ + w_- x_-$$

$$S_y = w_+ \bar{y}_+ + w_- \bar{y}_- + w_0 \bar{y}_0$$

$$S_{xx} = w_+ x_+^2 + w_- x_-^2$$

$$S_{xy} = w_+ x_+ \bar{y}_+ + w_- x_- \bar{y}_-$$

### 4.4 求解

行列式：$D = W \cdot S_{xx} - S_x^2$

**$|D| > 10^{-12}$ 时**：

$$G_{dc} = \frac{W \cdot S_{xy} - S_x \cdot S_y}{D} \tag{8}$$

$$O_{dc} = \frac{S_{xx} \cdot S_y - S_x \cdot S_{xy}}{D} \tag{9}$$

**$|D| \le 10^{-12}$ 时**（退化为两点法）：

$$G_{dc} = \frac{\bar{y}_+ - \bar{y}_-}{x_+ - x_-}, \quad O_{dc} = \bar{y}_0 \tag{10}$$

**安全校验**：$|G_{dc}| < 10^{-4} \Rightarrow$ 报错终止。

---

## 5. 交流拟合：单点比值

交流信号无零偏（正弦波均值为零），只有增益：

$$\bar{y}_{ac} = G_{ac} \cdot x_{ac} \tag{11}$$

$$G_{ac} = \frac{\bar{y}_{ac}}{x_{ac}} \tag{12}$$

$G_{ac}$ **始终为正值**（$x_{ac}$ 和 $\bar{y}_{ac}$ 都是 RMS，均为正数）。

**安全校验**：$|G_{ac}| < 10^{-4} \Rightarrow$ 报错终止。

## 6. 从物理增益推导校准系数

### 6.1 新代码校准公式回顾

| Layer | `Calibration.PhysToReg` 公式 | 说明 |
|:-----:|:--:|:--:|
| Layer 0 (DC) | $v_{cmd} = v_{desired} \cdot f_{dc} + b$ | 幅度值输入，含增益+零偏补偿 |
| Layer 1 (AC) | $v_{cmd} = v_{peak} \cdot f_{ac}$ | 峰值输入，仅增益补偿 |

### 6.2 DC 校准系数

要求对任意期望输出 $v_{desired}$，经过校准后实际输出等于 $v_{desired}$：

$$v_{desired} = G_{dc} \cdot \underbrace{(v_{desired} \cdot f_{dc} + b)}_{v_{cmd}} + O_{dc}$$

展开并比较系数：

$$\begin{cases} G_{dc} \cdot f_{dc} = 1 \\ G_{dc} \cdot b + O_{dc} = 0 \end{cases}$$

$$\boxed{f_{dc} = \frac{1}{G_{dc}}} \tag{13}$$

$$\boxed{b = -\frac{O_{dc}}{G_{dc}}} \tag{14}$$

### 6.3 AC 校准系数

AC 校准公式对峰值操作。由于 $G_{ac}$ 在峰值和 RMS 域中是相同的比例关系（$\sqrt{2}$ 因子在分子分母中抵消），直接可得：

$$v_{peak,desired} = G_{ac} \cdot \underbrace{(v_{peak,desired} \cdot f_{ac})}_{v_{cmd}}$$

$$\boxed{f_{ac} = \frac{1}{G_{ac}}} \tag{15}$$

$f_{ac}$ **始终为正值**。

> 证明 $G_{ac}$ 在峰值域和 RMS 域等价：
>
> $$G_{ac} = \frac{\bar{y}_{rms}}{x_{rms}} = \frac{\bar{y}_{rms} \cdot \sqrt{2}}{x_{rms} \cdot \sqrt{2}} = \frac{y_{peak}}{x_{peak}}$$

### 6.4 保存格式

`calibration.json`，key 为物理通道号，值为 `[bias, factor_dc, factor_ac]`：

```json
{ "0": [b, f_dc, f_ac] }
```

## 7. 完整数值示例（电压物理通道 0）

### 7.1 拟合自变量（§2 预计算物理值）

| 校准点 | 物理值 $x$ |
|:------:|:---------:|
| DC + | $x_+ = 100.00305$ V |
| DC - | $x_- = -100.00305$ V |
| DC 0 | $x_0 = 0$ V |
| AC | $x_{ac} = 57.73472$ V (RMS) |

### 7.2 拟合因变量（假设万用表测量结果）

| 步骤 | 万用表物理值 $\bar{y}$ | 方差 $\sigma^2$ |
|:----:|:--------------------:|:--------------:|
| ① AC 57.735V | $\bar{y}_{ac} = 60.622$ V (RMS) | — |
| ② DC 0V | $\bar{y}_0 = -0.020$ V | $\sigma_0^2 = 1.0 \times 10^{-8}$ |
| ③ DC +100V | $\bar{y}_+ = -104.980$ V | $\sigma_+^2 = 3.0 \times 10^{-6}$ |
| ④ DC -100V | $\bar{y}_- = +105.020$ V | $\sigma_-^2 = 3.2 \times 10^{-6}$ |

> $\bar{y}_+ < 0$ 说明功放反相。

### 7.3 DC 拟合

**权重**：$w_+ = 3.333 \times 10^5, \quad w_- = 3.125 \times 10^5, \quad w_0 = 1.0 \times 10^8$

**加权累计和**：

$$W = 1.00065 \times 10^8$$
$$S_x = w_+(100.003) + w_-(-100.003) = 2.083 \times 10^6$$
$$S_y = w_+(-104.980) + w_-(105.020) + w_0(-0.020) = -4.170 \times 10^6$$
$$S_{xx} = w_+(100.003)^2 + w_-(100.003)^2 = 6.458 \times 10^9$$
$$S_{xy} = w_+(100.003)(-104.980) + w_-(-100.003)(105.020) = -6.780 \times 10^9$$

**结果**：

$$D = 6.462 \times 10^{17}$$

$$G_{dc} = -1.0498 \qquad O_{dc} = -0.0198 \text{ V}$$

### 7.4 AC 拟合

$$G_{ac} = \frac{60.622}{57.73472} = 1.05001$$

### 7.5 校准系数

$$f_{dc} = \frac{1}{-1.0498} = -0.95258$$

$$b = -\frac{-0.0198}{-1.0498} = -0.01886 \text{ V}$$

$$f_{ac} = \frac{1}{1.05001} = 0.95238$$

### 7.6 保存

```json
{ "0": [-0.01886, -0.95258, 0.95238] }
```

### 7.7 验证

**DC +100V**：$v_{cmd} = 100 \times (-0.95258) + (-0.01886) = -95.277$ V
$y = (-1.0498)(-95.277) + (-0.0198) = 100.00$ V ✓

**AC 57.735V**：峰值 $v_{cmd} = 81.65 \times 0.95238 = 77.76$ V
$y_{peak} = 1.05001 \times 77.76 = 81.65$ V → $y_{rms} = 57.735$ V ✓
