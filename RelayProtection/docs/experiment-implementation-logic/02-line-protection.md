# 线路保护试验 — 实现逻辑与数学模型

> 模块标识：`lp_test`
> 被测对象：输电线路成套保护（距离、零序/相/负序过流、工频变化量阻抗、非全相零序、自动重合闸与后加速）
> 文档性质：以**继电保护测试原理**与**前端接口契约**为依据；不含代码实现细节。

---

## 1. 摘要

线路保护试验对一套线路保护装置施加"故障前 → 故障 → （跳闸）→ （重合）→ （转换/后加速）"
的完整电气过程，逐项考核其各保护功能的**动作值、动作时间、方向性、重合闸与后加速逻辑**。

与阻抗试验（多点边界搜索）不同，线路保护试验通常是**定点校验**：前端已根据定值与校验系数
算好每个测试点的故障电气量（阻抗 $z$、阻抗角 `ang`、短路电流 $i$、限时 `time` 等），
后端只负责**忠实地把这些点变换为各通道相量并按时序施加**，同时用硬件 SOE 记录保护出口时刻。

七种测试类型（`type` 0–6）共享同一套故障相量注入模型与状态机框架，差异在于：
被测物理量（阻抗/电流/电流序分量/工频变化量）、是否含故障转换、是否含重合闸。

---

## 2. 故障相量注入模型（七类共用）

所有类型最终都要把一个"测试点"映射为**三相电压 + 三相电流相量**。基本约定：

- 额定相电压 $V_N$（`sys.v`）、频率 $f$（`sys.f`）；负荷电流 $I_{\text{load}}\angle\theta_{\text{load}}$（`sys.iLoad`）。
- 故障阻抗 $Z=z\angle\text{ang}$；短路电流 $\dot I_f=i\angle 0^\circ$（取故障相为相位基准）。
- CT 极性 `ct`：指向母线时全部注入电流取负号。
- 方向 `dir`：`0` 正向（线路侧故障）、`1` 反向（母线侧故障）。反向时故障压降反相（详见 §2.5）。
- 零序补偿系数 $\underline{K}_L$ 由 `model.kl`（formula/p1/p2）确定，口径见 §2.6。

### 2.1 单相接地（ft = 0/1/2，故障相 $\phi$）

$$
\dot I_\phi=i\angle0^\circ,\quad 3\dot I_0=\dot I_\phi,\qquad
\dot V_\phi=Z\,\dot I_\phi\,(1+\underline{K}_L)
$$

非故障相维持额定对称电压、负荷电流。压降因子 $(1+\underline{K}_L)$ 将正序目标阻抗折算为接地环路实际压降。

### 2.2 两相相间（ft = 3/4/5，故障两相 $\phi,\psi$）

$$
\dot I_\phi=i\angle0^\circ,\quad \dot I_\psi=-\dot I_\phi,\qquad
\dot V_\phi-\dot V_\psi=2\,Z\,\dot I_f
$$

相间环路无零序补偿；将相间压降对称分配到两相（相对第三相健全电压）。

### 2.3 两相接地（ft = 6/7/8）

两故障相经过渡到地，既含相间分量又含零序分量，注入两故障相电流与对应的接地压降，
两相电压按相间 + 零序补偿叠加构造；第三相保持健全。

### 2.4 三相短路（ft = 9）

三相对称：每相 $\dot V_\phi=Z\,\dot I_\phi$，电流为正序对称三相，无零序补偿。

### 2.5 方向性

- **正向故障**（`dir`=0）：故障压降为正常方向，$\dot V_\phi$ 由额定值向故障值塌陷。
- **反向故障**（`dir`=1）：保护"看向线路"时母线侧故障使测量阻抗落入第三象限/反方向区，
  等效于把故障压降相位旋转 $180^\circ$（或令正向元件失压）。
  工频变化量类（type=4）反向更特殊：直接令故障电压置 0（见 §3.4）。

### 2.6 零序补偿系数口径（`model.kl`）

$$
\begin{cases}
\underline K_L=p_1\angle p_2,\ Z_{\text{loop}}=Z_L(1+\underline K_L), & \text{formula}=0\ \text{直接给定}\\[4pt]
Z_{\text{loop}}=R_L(1+p_1)+jX_L(1+p_2), & \text{formula}=1\ \text{分量法}(p_1=k_R,p_2=k_X,\text{分别补偿}R/X)\\[4pt]
\underline K_L=\dfrac{(z_0/z_1)-1}{3},\ z_0/z_1=p_1\angle p_2, & \text{formula}=2\ \text{阻抗比法}
\end{cases}
$$

测试仪的零序补偿必须与被测保护整定一致，否则接地距离测量阻抗会有系统偏差。
分量法（formula=1）对 R、X 分别按 $k_R=(R_0-R_1)/(3R_1)$、$k_X=(X_0-X_1)/(3X_1)$ 补偿（西门子 RE/XE 口径），
不等价于统一复数 $\underline K_L$。

## 3. 各类型的被测物理量与专门处理

### 3.1 type=0 距离保护（DISTANCE）

直接按 §2 注入目标阻抗 $Z=z\angle\text{ang}$。保护测量阻抗
$Z_{\text{m}}=Z$，校验其是否落入相应距离段（I/II/III 段）的动作区，并测段动作时间。
测试点 `time` 为该段限时窗口。

### 3.2 type=1 零序过流（ZERO_SEQ）

施加单相接地故障，保护检测零序电流 $3\dot I_0$。约定 **`i` 即 $3I_0$**：
单相接地时 $3I_0=I_f$，故直接令故障相电流为 `i`。零序过流对**对称负荷天然免疫**。

### 3.3 type=2 相过流（OC）

施加故障，保护检测**故障相电流**。约定 **`i` 即故障相电流**。

> ⚠️ 与距离/序分量元件不同，相过流元件**对负荷电流不免疫**：装置实测相电流是
> "故障分量 + 负荷电流"的矢量和。故 type=2 校验应令 `sys.iLoad.amp = 0`，
> 否则实测相电流 $\ne$ `i`。

### 3.4 type=3 负序过流（NEG_SEQ）

保护检测负序电流分量，约定 **`i` 即 $3I_2$**。注入换算：

$$
\text{相间/两相接地短路：}\ 3I_2=\sqrt3\,I_f\Rightarrow I_f=\tfrac{i}{\sqrt3};\qquad
\text{单相接地：}\ 3I_2=I_f\Rightarrow I_f=i.
$$

两种情形装置实测 $3I_2$ 均等于 `i`。负序元件对对称负荷免疫。三相对称短路无负序，不适用。

### 3.5 type=4 工频变化量阻抗保护（DELTA_Z）

**原理**：工频变化量（叠加分量/突变量）距离元件不直接测全量阻抗，而是测"故障前后工频量之差"。
定义叠加分量

$$
\Delta\dot U=\dot U_{\text{flt}}-\dot U_{\text{pre}},\qquad
\Delta\dot I=\dot I_{\text{flt}}-\dot I_{\text{pre}}.
$$

工频变化量距离的动作判据（典型形式）：

$$
\bigl|\,\Delta\dot U_{\text{op}}\,\bigr|=\bigl|\,\Delta\dot U-\Delta\dot I\cdot Z_{\text{set}}\,\bigr|
> U_{\text{float}},
$$

其中 $U_{\text{float}}$ 为随故障前电压"记忆"浮动的制动门槛。由于该判据只对"突变"响应，
**对稳态负荷与缓慢漂移天然免疫**，动作极快（亚周波）。

**测试构造**：前端用校验点系数 $m$ 把目标阻抗设为 $m\,Z_{\text{set}}$，
取 $m<1$（如 0.95）应动作、$m>1$（如 1.05）应不动作，以**夹逼**动作边界。后端施加：

1. 故障前态：额定对称电压 + 负荷电流（建立"记忆"参考）。
2. 故障态：按 §2 注入使**工频变化量**对应阻抗为 $m\,Z$ 的相量。

**厂家公式差异**（`formula`）：

- `formula=0`（南瑞）/ `formula=1`（许继）在**正方向**故障时对故障电压**叠加一个偏移项**
  （体现各家对 $\Delta\dot U_{\text{op}}$ 构造与浮动门槛的不同实现）。
- **反方向**故障：直接令故障电压置 0（叠加分量方向反转，正向元件不应动作）。

> 工程提示：两家偏移项中的具体系数（如灵敏角、门槛比例 1.05/1.3 等）属厂家私有口径，
> **须在真实装置上标定**后写入；本试验框架负责时序与相量注入，系数应可配置。

### 3.6 type=5 不灵敏零序 / 非全相零序（INSENS_ZS）

**原理**：单相接地经单相跳闸后，进入**非全相运行**（一相断开、两相运行）的重合死区。
此时系统不对称会产生零序电流，普通零序保护须**降低灵敏度或退出**以防误动；
而"不灵敏零序"段用于在非全相期间仍能切除新发生的故障。本试验考核该段在
**非全相 + 死区内转换故障**下的行为。

**真实时序**（本试验采用）：

```
正常 → 第一次单相接地(ft) → 单相跳闸 → 单相断开(非全相死区)
     → 死区内延时 delay → 转换故障(ft2, 维持开极) → 三跳终结(不重合)
```

- 第一次故障 `ft`∈{0,1,2}（单相接地），跳开故障相 → 该相断开（电流=0，线路侧 PT 时电压塌陷）。
- 经 `delay` 在**仍处开极**的状态下施加转换故障 `ft2`，并**维持先前跳开相为开极**
  （该相电流保持 0），以真实重现非全相零序工况。
- `after`：`0`=第一次跳闸后（死区内）施加转换；`1`=重合后施加（与 type=6 共用语义）。

### 3.7 type=6 自动重合闸及后加速（AUTO_RECLOSE）

**原理**：瞬时性故障被切除后，重合闸经整定延时合上断路器恢复供电；若为永久性故障，
重合于故障，后加速段**无延时快速跳闸**并闭锁重合。

**时序**（`nature` 决定瞬时/永久）：

```
正常 → 故障(ft) → 保护跳闸 → 断路器断开
     → 重合闸延时 → 重合
        ├─ nature=0 瞬时：合于正常 → 维持正常 → 结束
        └─ nature=1 永久：合于故障 → 后加速跳闸 → 结束
```

可选故障转换（`ft2` 存在时）：`after=1` 表示在**重合后**再施加转换故障。

**断路器位置回馈**：重合闸装置需要"断路器已断开"的位置信号才会启动重合。该信号由
测试仪 **DO（开出）模拟断路器辅助接点**提供（见 §5.3 mode=0）：跳闸进入开断态时翻转
DO（52a/52b），重合时翻回。**这是重合闸能被触发的关键**。

## 4. 状态机与时序

七类共用一个分支状态机（节点为电气态，箭头由 DI 跳闸/重合、定时超时、按键触发驱动）：

```
NORMAL ──trigger──▶ FAULT1 ──trip──▶ [CB跳闸延时] ──▶ CBOPEN(断开/开极)
   ▲                                                        │
   │                                              ┌──reclose─┴─[CB合闸延时]──▶ RECLOSE
   │                                              │                              │
 (点间)                                            │              ┌─nature=0─▶ 正常→结束
                                                   │              └─nature=1─▶ 合于故障→后加速跳→结束
                                  非全相: CBOPEN ──delay──▶ FAULT2(维持开极)──trip──▶ 结束
                                  重合后转换(after=1): RECLOSE ──delay──▶ FAULT2 ──trip──▶ 结束
```

- **触发方式**（`trigger.type`）：
  `0` KEY（前端 `next_node` 推进）、`1` TIME（故障前 `time` ms 后自动入故障）、`2` DI（开入触发）。
- **断路器模拟**（`ctrl.cb`）：`sim=true` 时在 FAULT→CBOPEN 间插入 `trip` ms 机械跳闸延时，
  在 CBOPEN→RECLOSE 间插入 `close` ms 合闸延时，逼真重现机械动作。
- **取下一组**：每组测试结束停在普通正常态，按顺序执行下一组；某组未测到动作仅视为该组完成、继续下一组；硬件错误才整体停止。

## 5. 前端控制变量（payload 全局）

### 5.1 Sys / Model / Ctrl

| 字段 | 物理意义 |
|---|---|
| `sys.v / f / iLoad` | 额定电压/频率/负荷电流 |
| `model.type` | 计算模型，固定 `0`（$I_f$ 恒定：以短路电流为已知量反算电压） |
| `model.kl` | 零序补偿系数（§2.6） |
| `ctrl.pt` | PT 安装侧（母线/线路）→ 影响开极相电压呈现 |
| `ctrl.ct` | CT 极性 → 注入电流参考方向 |
| `ctrl.cb.{sim,trip,close}` | 断路器跳/合机械延时模拟 |

### 5.2 DI（开入角色）

物理通道 `A/B/C`(0/1/2)、`R`(3)、`a/b/c`(4/5/6)、`r`(7)。

| 角色值 | 含义 |
|---|---|
| `0` OTHER | 不参与判据 |
| `1` THREE_TRIP | 三相跳闸接点 |
| `2` TRIP_ABC | 分相跳闸（A→a，B→b，C→c） |
| `3` RECLOSER | 重合闸接点（仅 R/r） |

跳闸判据按故障类型选取对应相的跳闸位（边沿触发）；重合判据监视 RECLOSER 位。

### 5.3 DO（断路器辅助接点 / 开出时序）

| `mode` | 行为 |
|---|---|
| `0` SYNC_WITH_RECLOSER | **断路器辅助接点模拟**：进入开断态翻转全部 DO（断开），重合时翻回（合闸）。**重合闸触发的关键。** |
| `1` DELAY_FLIP_ALL | 故障态内延时 `flipAll.delay` 翻转全部、保持 `flipAll.hold` 后翻回。 |
| `2` CUSTOM | 逐通道 `custom[ch].action`：`1`=FLIP（含 delay/hold），`0`=HOLD。 |

`init` 为故障前 DO 初值。DO 输出**跨状态保持**：仅当进入的新状态带 DO 动作时才改变，否则维持上一段。

### 5.4 Output（输出通道与同期电压）

| 字段 | 物理意义 |
|---|---|
| `output.vMode / iMode` | 电压/电流通道分组映射（A/B/C 对应物理通道组） |
| `output.ux` | 第四电压 $U_x$（同期/抽取电压）：`en` 使能、`type` 类型、`syncV/syncAng` 同期电压幅值/角，供重合闸同期检定 |

## 6. 测量与上报（SOE）

所有时间以 FPGA 硬件 SOE 时间戳为准，相对**故障施加时刻** $t_F$ 计：

| 量 | 定义 |
|---|---|
| `tripA/B/C` | 各相跳闸接点首次变位时刻 $-\,t_F$ |
| `reclose` | 重合闸接点变位时刻 $-\,t_F$ |
| `postAccel` | 重合（合于故障）后再次跳闸时刻（后加速动作时间） |

- 第一次跳闸前的相变位归入 `tripX`；重合后再次跳闸归入 `postAccel`。
- 非全相（type=5）：第一次单相跳闸记入 `tripX`，死区内转换故障的三跳记入对应相 `tripX`
  （相对 $t_F$，含 `delay` 偏移，前端可据 `delay` 折算）。

## 7. 算例

**例：type=6 永久性单相接地 + 重合 + 后加速，含断路器模拟与 DO 断路器接点。**

设 $V_N=57.735$ V，A 相接地 $z=2.0\,\Omega$、`ang`$=75^\circ$、$i=10$ A、$\underline{K}_L=0.667\angle0^\circ$，
`nature=1`，`cb.sim=true` (trip=close=20 ms)，DO `mode=0` init=0x01。

1. 故障前：三相额定。DO=0x01。
2. 故障：$\dot V_A=2.0\angle75^\circ\times10\times1.667=33.3\angle75^\circ$ V，A 相塌陷。
3. 保护跳 A（`tripA` ≈ 距离 I 段时间）→ 20 ms 后断路器断开 → 进 CBOPEN，DO 翻转为 0xFE（断开）。
4. 重合闸经整定延时检测到 DO=断开 → 重合接点动作（`reclose`）→ 20 ms 合闸 → DO 翻回 0x01。
5. 合于故障（永久）→ 后加速无延时再跳（`postAccel`）→ 结束。

## 8. 边界情形与工程注意

1. **type=2 须 `iLoad=0`**：相过流不免疫负荷。
2. **type=3 的 $3I_2$ 换算**：相间除以 $\sqrt3$，单相不换算。
3. **type=5 维持开极**：转换故障期间先前跳开相电流须保持 0，否则非全相工况失真。
4. **重合闸依赖 DO 断路器接点**：未配置 DO mode=0 时重合可能不被触发。
5. **工频变化量系数须标定**：南瑞/许继偏移项与门槛系数为厂家口径，需实机确认。
6. **SOE 计时**：动作时间一律用硬件时间戳，不用软件计时。
7. **点间不跳全局停止态**：多组连续执行，组间停在正常态节点。
