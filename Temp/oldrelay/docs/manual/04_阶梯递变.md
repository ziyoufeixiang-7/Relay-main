# 阶梯递变

### 简介

"阶梯递变"主要用于各种继电器动作/返回值的精密自动测试。指定的变量按给定的步长和每步时间作阶梯变化（Δ/Δt），可完成以下测试：

- 交流型继电器：电压继电器、电流继电器、功率方向继电器等的动作值、返回值、灵敏角以及动作时间测试；
- 直流型继电器：直流电压继电器、直流电流继电器、中间继电器等的动作值、返回值以及动作时间测试。

> 每步时间由 FPGA 硬件精确定时，精度达 µs 级别，不受上位机性能影响。

### 测试窗口

测试窗口包括以下设置区域：

- **变量选择**：选择试验变量，以及变量的变化方式等参数设置；
- **动作接点**：动作接点设置（开入通道、动作逻辑、防抖时间）；
- **开出设置**：设置复归状态和输出状态的开出量；
- **右视图**：实时显示当前输出的电压、电流幅值、角度和频率。

---

## 变量选择

### 变量选择

选择试验过程中的变量，可选择为相电压、相电流、频率和线电压等。

### 变化范围

设置变量的变化起点和终点。起点可以大于终点，也可以小于终点。

通常，变化范围的设置应能覆盖继电器的动作/返回值区间。

### 变化步长

设置变量的每步变化步长。

步长越小测试精度越高，但测试时间越长。根据测试要求选择合适的步长。

### 每步时间

变量按设定的步长变化时，每一步的保持时间（ms）。

通常，每步时间的设置应大于继电器的动作（或返回）时间。

---

## 变化方式

设置变化量的变化方式，"始"为变化范围的起点，"终"为终点：

- **始→终**：单程变化，只能测量动作值；
- **始→终→始**：双程变化，可以同时测量动作值、返回值，并自动计算出返回系数或灵敏角。

---

## 返回方式

设置变量的返回方式：

### 动作返回

变量在从起点→终点的变化过程中，一旦检测到继电器动作（开入变位），自动根据变化方式决定后续行为：

- 变化方式为"始→终"：**结束试验**，记录动作值；
- 变化方式为"始→终→始"：**改变变化方向**，向起点返回，同时记录动作值。返回过程中检测到继电器返回（开入恢复），记录返回值并结束。

### 全程变化

试验过程中，**无论继电器动作与否**，变量一直按设定的变化范围进行变化，直至到达终点或返回起点。

开入变位仅用于记录动作值和返回值，不影响扫频进程：
- 正向变化阶段：记录第一次开入变位对应的值 = 动作值
- 反向变化阶段：记录第一次开入变位对应的值 = 返回值

> **注**：灵敏角的测试必须采用"始→终→始"+"全程变化"的组合！

---

## 步进复归

### 启用步进复归

每步变化前是否需要输出一个复归状态（模拟故障前状态，使保护复归）。

- 常规继电器一般不需要步进复归，试验过程中变量连续变化；
- 某些微机型保护可能需要步进复归，变量呈脉冲式变化，即每步变化前先输出一段复归波形。

### 复归方式

| 方式 | 说明 |
|------|------|
| 单程复归 | 仅正向变化阶段每步前复归，反向变化时连续变化 |
| 全程复归 | 正向和反向变化阶段都每步前复归 |

通常，对于动作/返回值测试选择"单程复归"即可。

### 复归时间

每步变化前复归状态的输出时间（ms），应大于保护的复归时间，以保证保护可靠复归。

### 复归状态

设置复归期间的输出波形，通常为空载或额定值状态。

> 实验前复归和步进复归使用相同的复归波形。

### 脉冲波形时序

启用步进复归后，每步包含两个子阶段：

```
      复归态开出        输出态开出          复归态开出
 ─────┤ 复归期 ├──────────┤ 输出期 ├──────────┤ 复归期 ├───
      ← 复归时间 →       ← 每步时间 →       ← 复归时间 →
      输出复归波形        输出当前步测试波形   输出复归波形
```

---

## 实验前复归

勾选后，在试验开始前先输出一段复归波形，确保保护装置处于正常状态后再开始测试。

实验前复归使用与步进复归相同的复归波形。

---

## 动作接点

### 开入通道

设置参与动作/返回判断的开入通道。勾选的通道参与翻转判断。

### 动作逻辑

| 逻辑 | 说明 |
|------|------|
| 逻辑或 | 任何一个被选通道满足条件，动作成立 |
| 逻辑与 | 所有被选通道全部满足条件，动作成立 |

如果只选中一个通道，两种逻辑效果相同。

### 防抖时间

为避免继电器触点抖动造成误判，开入状态需保持一定时间后系统方予以确认。通常取 10～20ms。

> 防抖由 FPGA 硬件实现，精度可靠。

---

## 开出设置

设置复归状态和输出状态下的开出量。

### 复归态开出

设置复归期间开出量的状态（断开或闭合）。勾选表示闭合。

### 输出态翻转

设置复归结束进入输出期后，开出量是否翻转：

- **保持不变**：输出期开出量与复归期相同；
- **翻转**：输出期开出量与复归期相反。

---

## 辅助显示

右视图为试验过程的辅助显示区，实时显示当前输出的电压电流幅值、相位、频率等。

---

## 测试结果

试验结束后，系统输出以下测试结果：

| 结果字段 | 说明 |
|---------|------|
| 动作值 | 保护动作时的变量物理值 |
| 动作时间 | 从最后一步输出生效到开入变位的时间（ms，硬件精度） |
| 返回值 | 保护返回时的变量物理值（仅"始→终→始"模式） |
| 返回时间 | 开入恢复的时间（ms） |
| 返回系数 | 返回值 / 动作值 |
