# 初始化使用

烧录 Raspberry Pi OS Bookworm（Lite/无桌面）→ 联网开机 → 拷贝 `deploy/` 到树莓派，执行：

```bash
cd deploy
sudo bash init.sh     # 按提示选屏幕/字体，其余直接回车用默认
sudo reboot           # 重启后开机即全屏进入界面
```

说明：

- 每个模块 `[Y/n]`：回车=执行，`n`=跳过。
- 离线可跑（联网步骤失败自动跳过，联网后重跑补齐）。
- 可重复运行（幂等），用于只改某一项。
- 命令明细见 [`init命令清单.md`](init命令清单.md)。
