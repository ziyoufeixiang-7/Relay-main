# 部署指南

> 详细原理见《部署与OTA更新手册.md》。

## 一、全新设备初始化（最常用）

全新烧录 Raspberry Pi OS Bookworm Lite，SSH 登录后执行一行：

```bash
curl -sL http://47.98.48.17/update/relay12/init-pack.tar.gz | tar xz && sudo bash deploy/init.sh
```

脚本交互式引导 8 步：屏幕选择 → 串口 → 静默启动 → WiFi 权限 →
下载部署软件（含 systemd 服务、sudoers、USB 自动挂载）→ Kiosk 浏览器 → 系统精简 → 用户权限。
每步回车执行、输 `n` 跳过，完成后 `sudo reboot`。

> 初始化包有更新时，在开发机执行 `./deploy/publish_init.sh` 重新上传。

## 二、开发机本地部署（不走 OTA）

```bash
./deploy/build.sh        # 编译 + 打包（首次约 15~30 分钟）
./deploy/deploy.sh       # 把 deploy/output/dist/ 装到 /opt/RelayProtection/
sudo systemctl start relay-protection
```

## 三、设备日常更新

| 方式 | 操作 |
|------|------|
| 在线更新 | 设备界面：系统设置 → 检查更新 → 立即更新 |
| U 盘更新 | 更新包+`.sha256` 拷 U 盘根目录，插入设备 → 扫描 USB → 更新 |
| 回滚 | 系统设置 → 回滚（恢复到上一版本，备份在 `/opt/RelayProtection.bak/`） |

更新时设备校准数据 `config/calibration.json` 自动保留，不会被覆盖。

## 四、服务管理（设备上排查问题用）

```bash
sudo systemctl status relay-protection     # 状态
sudo systemctl restart relay-protection    # 重启
journalctl -u relay-protection -f          # 实时日志
/opt/RelayProtection/SysEngine.bin         # 前台直接运行（先 stop 服务）
curl http://47.98.48.17/update/relay12/version.json   # 看服务器最新版本
```

## 五、阿里云服务器（一次性配置）

新服务器才需要：装 nginx、建 `/var/www/relay-update/relay12/` 目录、
配置 `/update/` 路径映射、开放 80 端口。完整命令见手册第五节。
